# 笔夹 (pen_clamp) 说明

## 工具端法兰接口 (KWR75B, 已确认)
| 特征 | 值 | 来源 |
|------|-----|------|
| 螺纹孔 | 4×M6（螺栓自下往上拧入传感器） | 手册 §2.1 步骤4 + 外形参数 |
| 定位销孔 | **2×Φ6**（互为 180°） | 外形参数 §3 |
| 定心凸台 | Φ31.5（夹具需开 Φ32 过孔避让） | 外形参数 §3 |
| 销孔角度 | 相对 X/Y 轴 45° → `DOWEL_ANG=45` | 外形参数 §6 |

## 待实测参数 (打印前必填，卡尺复核)
| 参数 | 含义 | 当前占位值 | 状态 |
|------|------|-----------|------|
| BC_D | 工具端 4×M6 孔分布圆直径 | 50 mm | **待确认**（外形参数里 PCD Φ63 写在"转接法兰"名下，归属存疑） |
| DOWEL_R | 2×Φ6 销孔径向距离 | 12 mm | **待实测**（外形参数未给出） |
| DOWEL_ANG | Φ6 销相对 M6 孔角度 | 45° | ✅ 已确认 |

> ⚠ `BC_D`/`DOWEL_R` 读错会导致夹具对不上孔、装不上。设备回来后用卡尺量一次（分度圆 + 销孔径向距）再填，然后跑 Task 2 渲染打印。

## 装配顺序
1. 法兰板中心 Φ32 过孔套进传感器 Φ31.5 凸台。
2. 2×Φ6 销定位 + 4×M6 螺栓自下往上拧入传感器工具端螺纹孔。
3. 笔杆自下而上穿过套筒，滑动到合适位置（笔尖伸出下方合适长度，笔顶可抵凸台面）。
4. 侧向螺丝顶紧，笔垂直纸面、无晃动。

## 换笔
松开侧向螺丝 → 抽出旧笔 → 插入新笔滑动到同一笔尖位置 → 重新顶紧。
笔尖位置一致则无需重标 TCP 偏移。
