# 笔夹 (pen_clamp) 说明

## 工具端法兰接口 (KWR75B, 已确认)
| 特征 | 值 | 来源 |
|------|-----|------|
| 螺纹孔 | 4×M6（螺栓自下往上拧入传感器） | 手册 §2.1 步骤4 + 外形参数 |
| 定位销孔 | **2×Φ6**（互为 180°） | 外形参数 §3 |
| 定心凸台 | Φ31.5（夹具需开 Φ32 过孔避让） | 外形参数 §3 |
| 销孔角度 | 相对 X/Y 轴 45° → `DOWEL_ANG=45` | 外形参数 §6 |

## 工具端法兰接口参数 (已全部确认)
| 参数 | 含义 | 值 | 依据 |
|------|------|-----------|------|
| BC_D | 工具端 4×M6 孔分布圆直径 | 50 mm | GB/T 14468.1-50-4-M6 分度圆 Φ50 |
| DOWEL_R | 2×Φ6 销孔径向距离 | 25 mm | 落在 Φ50 分度圆上，R=25（用户实测确认） |
| DOWEL_ANG | Φ6 销相对 M6 孔角度 | 45° | 相对 X/Y 轴 45°（外形参数 §6） |

> 依据：CR 系列末端法兰符合国标 `GB/T 14468.1-50-4-M6`（= ISO 9409-1），分度圆 Φ50 + 4×M6；传感器工具端定心凸台 Φ31.5 等于该标准中心孔 Φ31.5，即工具端为同一标准"通用接口"（CR 手册 5.1.3 / 力传感器手册 §2.1 步骤4）。

## 装配顺序
1. 法兰板中心 Φ32 过孔套进传感器 Φ31.5 凸台。
2. 2×Φ6 销定位 + 4×M6 螺栓自下往上拧入传感器工具端螺纹孔。
3. 笔杆自下而上穿过套筒，滑动到合适位置（笔尖伸出下方合适长度，笔顶可抵凸台面）。
4. 侧向螺丝顶紧，笔垂直纸面、无晃动。

## 换笔
松开侧向螺丝 → 抽出旧笔 → 插入新笔滑动到同一笔尖位置 → 重新顶紧。
笔尖位置一致则无需重标 TCP 偏移。
