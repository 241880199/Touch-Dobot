# 笔夹 (pen_clamp) 说明

## 设计原理
- 力传递：笔尾端（笔顶）轴向顶住传感器 Φ31.5 凸台面，书写力沿笔轴直传传感器。
- 夹头只扶正笔杆（共轴）并轻夹防落，**不承书写力**。
- 双 Φ8 光轴 + 滑动块：适配笔长、夹持点沿柱可调。
- 自定心夹头：适配固定 Φ8 毛笔（S 档）；由锁紧环 3 颗 M4 径向顶丝夹紧（一瓣一颗）。

## 传感器接口参数 (已确认)
| 参数 | 值 | 依据 |
|------|-----|------|
| BC_D | 50 mm | GB/T 14468.1-50-4-M6 |
| DOWEL_R | 25 mm | 实测确认 |
| DOWEL_ANG | 45° | 外形参数 §6 |
| 凸台直径/高度 | Φ31.5 / 7 mm | 高度=31.5-24.5，打印前卡尺复核 |

## 笔适配范围
| 项 | 值 |
|----|-----|
| 笔杆直径 | 8mm（固定毛笔，S 档夹头）|
| 笔总长 | 220mm |
| 夹持点 | 沿柱可调（落在手握位，离笔尖 50~120mm）|

## 零件清单
见 `Hardware/stl/`：`flange` / `block` / `collet_s` / `ring`（`tiebar` 已删除）。
采购件：Φ8 光轴×2(190mm，45#软轴截断、不打孔)、M4×35 内六角×2、M4×12 顶丝×3（锁紧环径向夹笔）、M4×10 顶丝×3（块侧锁高 1 + 耳座锁光轴 2）、M4 六角螺母×8（块顶 2 + 块侧锁高 1 + 锁紧环径向 3 + 耳座锁光轴 2）、M6×16 螺栓×4（按传感器孔深复核）、Φ6 销×2。

## 装配顺序
1. 先把 2 颗 M4 螺母自法兰顶面放入两个耳座的径向螺母槽（侧放入槽，同锁高/锁紧环螺母）；法兰板中心 Φ32 过孔套进传感器 Φ31.5 凸台（螺母被传感器面兜住、不外脱）。
2. 2×Φ6 销定位 + 4×M6 螺栓自下往上拧入传感器。
3. 两光轴插入耳座（插到底，光轴端贴法兰底面），各耳座外圆的 M4 顶丝径向旋入螺母、尖端顶光轴压坑锁死——**机械锁死、不靠摩擦/胶、可松开拆卸**；再套上滑动块（光轴下端无需横梁，门架由块的两光轴孔+法兰双耳座承担）。
4. 夹头（S 档 Φ8）从块顶放入中央座。
5. 先把 3 颗 M4 螺母自锁紧环顶面放入 3 个径向螺母槽；锁紧环（宽松直孔圆盘）自下套上夹头三瓣，2×M4 螺栓自下穿过锁紧环+块、拧入块顶面螺母——只固定环位置，不承夹紧（夹紧由第 6 步 3 颗径向顶丝完成）。

## 紧固件处理（六角螺母嵌槽，免热熔/免攻丝）
以下螺纹位**不用热熔、不用攻丝**，全部由 **M4 六角螺母（GB/T 6170，对边 7mm / 厚 3.2mm）** 嵌槽提供螺纹（槽对边 7.4mm，打印缩水后呈轻过盈；旧版 7.0 太紧压不进；靠螺栓/顶丝张力把螺母压向槽壁台阶，不外脱）：

| 位置 | 嵌槽 | 用途 | 装配 |
|------|------|------|------|
| 块顶面 2×M4 螺母槽 | 开口向上，深 3.6 | 接收锁紧环竖直螺栓、固定环位置 | 螺母自上放入槽、螺栓张力压向槽底台阶（无需过盈）；螺栓自下穿过锁紧环+块、拧入螺母 |
| 块侧锁高顶丝孔 | Φ4.5 过孔 + 顶面放入的 M4 螺母槽（+X 壁 2mm 挡螺母） | 顶丝拧入螺母、尖端顶光轴锁高 | M4 螺母自顶面放入槽、顶丝自 +X 拧入；拧紧把螺母压向 +X 壁（Φ4.5<7mm 不外脱） |
| 锁紧环 3×径向螺母槽 | 环顶面开口矩形槽 + 外壁 2mm 挡螺母 | 3×M4 顶丝径向旋入压三瓣夹笔 | 3 颗 M4 螺母自环顶面放入槽、顶丝自环外圆 Φ4.5 过孔径向拧入；拧紧把螺母压向外壁（Φ4.5<7mm 不外脱） |
| 耳座 2×径向锁光轴顶丝孔 | Φ4.5 过孔 + 顶面放入的 M4 螺母槽（外壁 2mm 挡螺母） | 顶丝拧入螺母、尖端顶光轴压坑锁死 | M4 螺母自法兰顶面放入槽（侧放）、顶丝自耳座外圆径向拧入；拧紧把螺母压向外壁（Φ4.5<7mm 不外脱） |
| 锁紧环 2×M4 竖直过孔 | `RING_BOLT_D=4.5` | 螺栓杆身穿过（不需螺纹），只固定环 | 保持原样 |

- **最终紧固件 BOM**：M4×35 内六角×2（锁紧环→块顶固定）+ M4×12 顶丝×3（锁紧环径向夹笔）+ M4×10 顶丝×3（块侧锁高 1 + 耳座锁光轴 2）+ M4 六角螺母×8（块顶 2 + 块侧锁高 1 + 锁紧环径向 3 + 耳座锁光轴 2）+ M6×16 螺栓×4（按传感器孔深复核）+ Φ6 销×2。

## 装笔
1. 笔从下方穿入夹头中央孔。
2. 向上推笔，直到笔顶顶住传感器凸台面。
3. 下滑动块使夹头落在手握位 → 拧紧块侧 M4 锁高顶丝（顶丝拧入块侧顶面放入的螺母、尖端顶光轴）。
4. 依次拧紧锁紧环 3 颗 M4 径向顶丝轻夹笔（一瓣一颗、120° 均布；只扶正+防落，勿死拧）。

## 换笔
固定 Φ8×220 毛笔，无需换档。松锁紧环 3 颗径向顶丝 → 抽笔 → 插回顶到位 → 锁高 → 拧紧径向顶丝轻夹。
每次装笔都「顶到位」；笔长固定，**TCP 偏移标定一次即可复用**（复用 TcpCalibration 流程）。

## 已知限制 / 打印前待测
- **夹头孔径 = 笔杆 8mm（S 档）**：FDM 内孔偏小，8mm 孔实打 ~7.7~7.9，与 8mm 笔为轻微过盈，三瓣略微张开即可插入——预期内的自定心效果，非缺陷；若插入太紧，微调 `COLLET_BORE` +0.1~0.2 重导 `collet_s.stl`。
- **三瓣缝宽 `FINGER_GAP=2.0`（已扩）**：三瓣可收紧量 = `3·FINGER_GAP/π ≈ 1.91mm`，配合孔径取档位中点。缝 2mm 也避免打印粘连；若日后想夹更死或缝宽影响定心，改 `FINGER_GAP` 一处重导即可。
- **锁紧环为宽松直孔 `RING_ID=25.5`（手指顶 Φ25 +0.5）+ 3 颗径向顶丝**：直孔只保证套上三瓣，夹紧全由 3 颗 M4×12 顶丝径向压三瓣完成（一瓣一颗、可控可调）。若打印内孔仍偏紧套不进，微调 `RING_ID` +0.1~0.2 重导 `ring.stl`；顶丝尖端顶塑料瓣会留浅凹痕，属预期。
- **笔顶非平面顶不住**：凸台面与笔顶之间加一片 Φ8~16 平垫片。
- **抬笔瞬间笔脱离传感器**：夹头轻夹通常已足够（笔重远小于书写力）；仍晃则在传感器侧加轻弹簧顶柱。
