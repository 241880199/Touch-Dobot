# 笔夹 (pen_clamp) 说明

## 设计原理
- 力传递：笔尾端（笔顶）轴向顶住传感器 Φ31.5 凸台面，书写力沿笔轴直传传感器。
- 夹头只扶正笔杆（共轴）并轻夹防落，**不承书写力**。
- 双 Φ8 光轴 + 滑动块：适配笔长、夹持点沿柱可调。
- 三档自定心夹头：适配笔杆直径 6~16mm，换档只换夹头。

## 传感器接口参数 (已确认)
| 参数 | 值 | 依据 |
|------|-----|------|
| BC_D | 50 mm | GB/T 14468.1-50-4-M6 |
| DOWEL_R | 25 mm | 实测确认 |
| DOWEL_ANG | 45° | 外形参数 §6 |
| 凸台直径/高度 | Φ31.5 / 7 mm | 高度=31.5-24.5，打印前卡尺复核 |

## 笔适配范围
| 项 | 值 |
|----|-----|
| 笔杆直径 | 6~16mm（夹头 6-10 / 10-13 / 13-16 三档）|
| 笔总长 | 170~300mm |
| 夹持点 | 沿柱可调（落在手握位，离笔尖 50~120mm）|

## 零件清单
见 `Hardware/stl/`：`flange` / `block` / `tiebar` / `collet_s|m|l` / `ring`。
采购件：Φ8 光轴×2(250mm)、M4×20 内六角×2、M4×10 内六角×1、M6×16 螺栓×4（按传感器孔深复核）、Φ6 销×2。

## 装配顺序
1. 法兰板中心 Φ32 过孔套进传感器 Φ31.5 凸台。
2. 2×Φ6 销定位 + 4×M6 螺栓自下往上拧入传感器。
3. 两光轴压入法兰耳座（可点胶），套上滑动块，底部横梁固定光轴下端。
4. 按笔径选夹头档，夹头从块顶放入中央座。
5. 锁紧环自下套上夹头三瓣，2×M4 螺栓拧入块底面（先不收紧）。

## 紧固件处理（打印后必做，否则无法锁紧）
以下孔**打印出来都是未攻丝的光孔（过孔）**，直接拧螺丝锁不住，需先处理：

| 位置 | 孔径 | 用途 | 处理方式 |
|------|------|------|----------|
| 块侧锁高螺丝孔 | `BLOCK_LOCK_D=4.5` | 顶住光轴、锁死块高度（沿 +X 自块侧面钻入） | Φ4.5 正好匹配 M4 热熔嵌件（直接压入），或攻 M4，或穿通配 M4 螺母。 |
| 块底面 2×M4 螺栓孔 | `RING_BOLT_D=4.5` | 接收锁紧环螺栓螺纹、把环上拉夹紧 | 这两孔要**吃住螺栓螺纹**：攻 M4 或嵌 M4 热熔嵌件（Φ4.5 正好匹配），或穿通配 M4 螺母。 |
| 锁紧环 2×M4 过孔 | `RING_BOLT_D=4.5` | 螺栓杆身穿过（不需螺纹） | 保持原样即可（螺栓光杆过孔，正确）。 |

- **选择**：推荐「块底 2 孔 + 块侧 1 孔」全部嵌 **M4 热熔嵌件**（黄铜，外径 Φ4.5），热熔枪压入；三孔孔径均已 Φ4.5，免扩孔。
- **最终紧固件 BOM**：M4×20 内六角×2（锁紧环→块底，环厚 12mm + 块内螺纹 ~8mm）+ M4×10 内六角/顶丝×1（块侧锁高）+ M4 热熔嵌件×3（或 M4 螺母×3 替代）+ M6×16 螺栓×4（按传感器孔深复核）+ Φ6 销×2。

## 装笔
1. 笔从下方穿入夹头中央孔。
2. 向上推笔，直到笔顶顶住传感器凸台面。
3. 下滑动块使夹头落在手握位 → 拧紧块侧 M4 锁高螺丝。
4. 拧紧锁紧环 2×M4 螺栓轻夹笔（只扶正+防落，勿死拧）。

## 换笔
松锁紧环螺栓 → 抽旧笔 → 换档(如需) → 插新笔顶到位 → 锁高 → 轻夹。
每次装笔都「顶到位」，笔尖相对传感器高度随笔长变 → **TCP 偏移需重标**（复用 TcpCalibration 流程）。

## 已知限制 / 打印前待测
- **锥面配合为线接触（锥角不匹配）**：三瓣锥方向已修正为「自由端(下)窄 Φ22、基端(上)宽 Φ25」，压环上移即收紧，夹紧功能成立（`22 < 22.5 < 25 < 25.5`）。但锁紧环内锥 12mm 高内径从 25.5 收到 22.5（锥度 3/12），夹头三瓣锥 16mm 高外径从 25 收到 22（锥度 3/16），锥角仍不匹配：环更陡，套上后环内锥最窄的上沿(Φ22.5)先碰到三瓣，接触是一条线（在环上沿附近）而非整个锥面贴合。若要全锥面贴合，把 `RING_L` 改到 ≈16mm（或改三瓣锥度）即可，本次范围外。
- **夹头孔径为档位中点**：三档孔径取各自笔径区间中点（8 / 11.5 / 14.5mm）。若笔径落在区间上半段（如 10mm 笔用 S 档、13mm 笔用 M 档），笔杆略大于孔径，为轻微过盈的压入配合，三瓣需略微张开——这是预期内的自定心效果，非缺陷。
- **三瓣缝宽 `FINGER_GAP=2.0`（已扩）**：三瓣可收紧量 = `3·FINGER_GAP/π ≈ 1.91mm`，配合孔径取档位中点，各档实际可夹范围 S≈6.1–10 / M≈9.6–13 / L≈12.6–16（覆盖标称下限）。缝 2mm 也避免打印粘连。若日后想夹更死或缝宽影响定心，改 `FINGER_GAP` 一处重导即可。
- **笔顶非平面顶不住**：凸台面与笔顶之间加一片 Φ8~16 平垫片。
- **抬笔瞬间笔脱离传感器**：夹头轻夹通常已足够（笔重远小于书写力）；仍晃则在传感器侧加轻弹簧顶柱。
