# 笔夹 (pen_clamp) 说明

## 设计原理
- 力传递：笔尾端（笔顶）轴向顶住传感器 Φ31.5 凸台面，书写力沿笔轴直传传感器。
- 夹头只扶正笔杆（共轴）并轻夹防落，**不承书写力**。
- 双 Φ8 光轴 + 滑动块：适配笔长、夹持点沿柱可调。
- 三档自定心夹头：适配笔杆直径 6~16mm，换档只换夹头。

## 传感器接口参数 (已确认)
| 参数 | 值 | 依据 |
|------|-----|------|
| BC_D | 50 mm | GB/T 14468.1-50-4-M6 |
| DOWEL_R | 25 mm | 实测确认 |
| DOWEL_ANG | 45° | 外形参数 §6 |
| 凸台直径/高度 | Φ31.5 / 7 mm | 高度=31.5-24.5，打印前卡尺复核 |

## 笔适配范围
| 项 | 值 |
|----|-----|
| 笔杆直径 | 6~16mm（夹头 6-10 / 10-13 / 13-16 三档）|
| 笔总长 | 170~300mm |
| 夹持点 | 沿柱可调（落在手握位，离笔尖 50~120mm）|

## 零件清单
见 `Hardware/stl/`：`flange` / `block` / `tiebar` / `collet_s|m|l` / `ring`。
采购件：Φ8 光轴×2(250mm)、M4×16 内六角×2、M4×10 内六角×1、M6 螺栓×4、Φ6 销×2。

## 装配顺序
1. 法兰板中心 Φ32 过孔套进传感器 Φ31.5 凸台。
2. 2×Φ6 销定位 + 4×M6 螺栓自下往上拧入传感器。
3. 两光轴压入法兰耳座（可点胶），套上滑动块，底部横梁固定光轴下端。
4. 按笔径选夹头档，夹头从块顶放入中央座。
5. 锁紧环自下套上夹头三瓣，2×M4 螺栓拧入块底面（先不收紧）。

## 紧固件处理（打印后必做，否则无法锁紧）
以下孔**打印出来都是未攻丝的光孔（过孔）**，直接拧螺丝锁不住，需先处理：

| 位置 | 孔径 | 用途 | 处理方式 |
|------|------|------|----------|
| 块侧锁高螺丝孔 | `BLOCK_LOCK_D=4.2` | 径向顶住光轴、锁死块高度 | Φ4.2 为 M4 过孔，**不能直接攻丝**。三选一：①改钻 Φ3.3 底孔后攻 M4；②嵌 M4 热熔嵌件（Φ4.5，需把孔扩到 Φ4.5）；③M4×10 顶丝 + M4 螺母外锁。 |
| 块底面 2×M4 螺栓孔 | `RING_BOLT_D=4.5` | 接收锁紧环螺栓螺纹、把环上拉夹紧 | 这两孔要**吃住螺栓螺纹**：攻 M4 或嵌 M4 热熔嵌件（Φ4.5 正好匹配），或穿通配 M4 螺母。 |
| 锁紧环 2×M4 过孔 | `RING_BOLT_D=4.5` | 螺栓杆身穿过（不需螺纹） | 保持原样即可（螺栓光杆过孔，正确）。 |

- **选择**：推荐「块底 2 孔 + 块侧 1 孔」全部嵌 **M4 热熔嵌件**（黄铜，外径 Φ4.5），热熔枪压入；块底两孔外径正好 Φ4.5 免扩孔，块侧锁高孔需从 Φ4.2 扩到 Φ4.5。
- **最终紧固件 BOM**：M4×16 内六角×2（锁紧环→块底）+ M4×10 内六角/顶丝×1（块侧锁高）+ M4 热熔嵌件×3（或 M4 螺母×3 替代）+ M6 螺栓×4 + Φ6 销×2。

## 装笔
1. 笔从下方穿入夹头中央孔。
2. 向上推笔，直到笔顶顶住传感器凸台面。
3. 下滑动块使夹头落在手握位 → 拧紧块侧 M4 锁高螺丝。
4. 拧紧锁紧环 2×M4 螺栓轻夹笔（只扶正+防落，勿死拧）。

## 换笔
松锁紧环螺栓 → 抽旧笔 → 换档(如需) → 插新笔顶到位 → 锁高 → 轻夹。
每次装笔都「顶到位」，笔尖相对传感器高度随笔长变 → **TCP 偏移需重标**（复用 TcpCalibration 流程）。

## 已知限制 / 打印前待测
- **锥面配合为线接触（锥角不匹配）**：锁紧环内锥 12mm 高内径从 25.5 收到 22.5（锥度 3/12），而夹头三瓣锥 16mm 高外径从 25 收到 22（锥度 3/16）。环更陡，套上后环内锥**最窄的上沿(Φ22.5)先碰到三瓣**，接触是一条线（在环上沿附近），不是整个锥面贴合。仍能夹紧：`22.5 < 25 < 25.5` 成立，环上移即收紧——**这不是装配失败**。若要全锥面贴合，把 `RING_L` 改到 ≈16mm（或改三瓣锥度）即可，本次范围外。
- **三瓣缝 0.8mm 过窄，打印易粘连**：三瓣缝宽在 `split_collet` 里是单个 `cube` 的 0.8 尺寸（`cube([…, 0.8, …])`）。若打印后三瓣粘死，把该值改成 **1.0~1.2mm** 重新导出对应夹头即可（一处改动）。
- **笔顶非平面顶不住**：凸台面与笔顶之间加一片 Φ8~16 平垫片。
- **抬笔瞬间笔脱离传感器**：夹头轻夹通常已足够（笔重远小于书写力）；仍晃则在传感器侧加轻弹簧顶柱。
