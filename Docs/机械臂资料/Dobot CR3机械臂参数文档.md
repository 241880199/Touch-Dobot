## 三、奇异位置（必须规避）

机械臂在以下构型时会失去一个或多个自由度，导致逆解失败或运动异常：

1. **肩关节奇异**  
   J5轴与J6轴的交点落在J1轴与J2轴所构成的平面内。  
   *典型表现：机械臂“肩膀”卡死，无法继续运动。*

2. **肘关节奇异**  
   大臂与小臂完全伸展成一条直线（J3 ≈ 0° 且 J2 处于特定角度）。  
   *典型表现：肘部锁死，末端无法沿某些方向移动。*

3. **腕关节奇异**  
   J4轴与J6轴平行（或共线）。  
   *典型表现：手腕无法灵活转动，运动规划报错。*

> **算法建议**：在逆解或轨迹规划前，可预先判断目标点是否接近奇异区域（例如通过雅可比矩阵的条件数），必要时采用关节运动（MovJ）而非直线运动（MovL）绕过奇异点。

## 四、坐标系定义

### 1. 关节坐标系
- 以各关节的旋转角度（J1~J6）为变量。
- 运动时 TCP 轨迹不一定是直线，但不会受奇异位置限制。
- **用途**：适用于避开奇异点的运动、回零、打包等。

### 2. 用户坐标系（基坐标系）
- 原点：机械臂底座中心点。
- 默认方向：  
  - X 轴：正方向由底座中心指向重载插座相对侧？  
  - Y 轴：正方向为 **重载插座面对的方向**（见手册图4.2）。  
  - Z 轴：竖直向上（符合右手定则）。
- **用途**：定义工件、传送带或外部设备的工作平面。

### 3. 工具坐标系（TCP）
- 原点：末端法兰盘中心。
- 默认方向：  
  - X 轴：正方向与航空插座方向有关？  
  - Y 轴：正方向为 **航空插座的相反方向**（见手册图4.3）。  
  - Z 轴：沿法兰轴线向外。
- **用途**：安装夹爪、焊枪等工具后，标定 TCP 偏移，使运动指令作用于实际工具中心。

## 五、零点位姿与机械零点

- **零点位姿**：所有关节角度均为 0° 的状态，此时机械臂呈竖直姿态（J1 任意，J2=0，J3=0，J4=0，J5=0，J6=0）。
- **零点标识**：每个关节处贴有对齐贴纸，当贴纸对齐时即该关节为 0°。
- **重新标定**：更换传动部件或发生碰撞后，可将各关节手动对齐贴纸，再通过软件进行零点标定。

## 七、末端负载曲线

CR3 的最大允许负载取决于负载重心位置，具体由 **偏心距** `r = √(X² + Y²)` 和 **Z 向偏移** 决定。

- **曲线图**：见手册图 5.4（无法直接复制图片，但核心规律如下）  
  - 当负载重心靠近法兰中心（r 和 Z 较小）时，允许 3 kg 满载。  
  - 当重心向外偏移时，允许负载迅速下降，例如 r=10 cm、Z=5 cm 时，仅允许约 2.8 kg。
- **算法影响**：在力反馈中，若机械臂末端安装了较重的工具，**负载设置不正确**会导致碰撞检测误触发或拖拽失控。应通过软件（CRStudio 的“末端负载”页面）准确设置重量和偏心坐标。

## 八、制动距离与急停响应

在 100% 速度、最大负载、最大臂展下，各关节急停数据如下：

| 关节 | 停止时间 | 停止距离（末端弧长） |
|------|----------|----------------------|
| J1 | 122 ms | 84.89 mm |
| J2 | 165 ms | 83.97 mm |

> **安全警示**：急停后机械臂会因惯性继续运动一段距离，设计工作空间时需预留该缓冲区域。

## 九、I/O 与通信接口（用于力传感器接入）

### 控制柜（CC162）相关接口
- **数字输入**：16 路（PNP，24V）
- **数字输出**：16 路（复用，高边开关，单路 500mA，总 2A）
- **模拟输入**：2 路（0~10V 或 4~20mA，可配置）
- **模拟输出**：2 路（0~10V 或 4~20mA）
- **增量编码器**：1 路 ABZ 输入（用于传送带或外部位置反馈）

### 机械臂末端接口（航插）
| 引脚 | 信号 | 说明 |
|------|------|------|
| 1 | 485A / AI1 | RS485 A 或 模拟输入1 |
| 2 | 485B / AI2 | RS485 B 或 模拟输入2 |
| 3 | DI_2 | 数字输入2 |
| 4 | DI_1 | 数字输入1 |
| 5 | 24V | 24V 输出（1A 额定，2A 峰值） |
| 6 | DO_2 | 数字输出2（NPN） |
| 7 | DO_1 | 数字输出1（NPN） |
| 8 | GND | 地 |

> **力传感器接入建议**：若末端安装六维力传感器，通常使用 **RS485（Modbus RTU）** 或 **模拟输入（AI）** 读取力/力矩数据。CR3 末端支持这两种方式，可直接连接传感器。

## 十、安全相关参数（影响力反馈策略）

| 功能 | 说明 |
|------|------|
| 碰撞检测 | 5 级灵敏度可调（5 级最灵敏），碰撞后可选择停止/暂停/回退/进入拖拽模式 |
| 缩减模式 | 外部安全输入触发时，自动限制关节速度与 TCP 速度 |
| 紧急停止 | 硬件急停开关（1 类停止），也可通过外部安全 I/O 扩展 |
| 关节抱闸 | 下使能后自动锁死，防止坠落；手动释放需支撑 |

> **力反馈映射建议**：当机械臂末端接触环境产生外力时，可通过读取关节电流估算外力（或直接使用六维力传感器）。将此力值经比例缩放（例如 1:1 或 1:0.5）后发送给 Touch 设备渲染，可实现“遥操作力觉临场感”。
