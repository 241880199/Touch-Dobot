# Task brief — 联合估计 `A`，再看两把门接不接受

## 背景（已确立，不要重推）

负载标定的模型是：

```
F_i = b_F + A · g_i            A: 3×3
M_i = b_M + c_s × (A · g_i)    c_s: 3
```

**`A` 目前只由力通道估出来**（`A_F`），力矩通道再用它。而力矩通道其实**对 `A` 也有信息**
（经 `c_s × A·g`）。**"`A` 只是估得差"（甲）**这个诊断已经成立：λ 扫描证明存在
`A(λ) = A_F + λ·D` 让**两把门同时接受**：

```
新采集 2026-09-19 18:49:55:  λ ∈ [0.622638498514, 0.785411313319]
中点 λ=0.704:  力 2.433 / 门限 2.869 ✓     力矩 3.451 / 门限 4.909 ✓
```

**但 λ 是挑出来让两把门通过的 —— 那不是估计，那是对着判据做拟合。** 本任务要的是**统计上站得住的**估计。

出处：`Docs/superpowers/evidence/lambda-scan-report.md`、
`moment-model-structure-report.md`、`moment-gate-dA-correction-report.md`。

## ★ 最重要的纪律：**先定估计器，再看门**

**估计器的构造必须在"看门的结果"之前定死**，并写清楚它是什么、为什么是它。
**不得**事后调整权重/自由度/口径去让门通过。若估计器是 principled 的而门依然拒绝，
**那个结果就是结论** —— 照实报，不要回头改估计器。

## 要做的

### 1. 按两通道各自的噪声加权，联合估 `A`

把力方程与力矩方程放进**同一个**加权最小二乘：未知量 `(b_F, A, b_M, c_s)`。
注意 `M = b_M + c_s × (A·g)` 对 `(c_s, A)` 是**双线性**的 ⇒ 非线性最小二乘
（Gauss–Newton / 交替最小化都行，但**收敛必须被验证**，不是"跑几轮看着像收敛"）。

**权重必须来自实测噪声，不是猜的：**
- 力通道的 `Cov(A_F)`：用 **sandwich** `(JᵀJ)⁻¹JᵀΣJ(JᵀJ)⁻¹`，`Σ` 由逐姿态噪声给出
  —— **不要用生产的 `paramSigma`**：`moment-gate-dA-correction-report.md` 已证它用了
  跨 4~5 倍异方差通道池化的 `s2F`，A 块偏大 2.4~2.5 倍。sandwich 那份实测吻合 ≤0.5%。
- 力矩侧同理，用逐姿态的力矩噪声。

**构造与权重写清楚**（哪些量、什么口径、为什么），**然后才跑门。**

### 2. 把两把门跑在估出来的 `A` 上

对估出的 `A`，用**生产 `fitRaw`** 报：
- 力通道 `chi2RepForceRatio` 对它自己的门限
- 力矩 `lackOfFitMomentRatio` 对它自己的门限

**判据：两把门是否都接受。**

### 3. 与 λ 线的关系（交叉核对，不是判据）

把 `A_joint` **最小二乘投影**到 λ 线上，报出对应的 λ。

⚠ **注意**：`A_joint` 一般**不在** λ 线上 —— λ 是一维族，而最优组合是**矩阵加权**的。
所以"λ 落不落在区间内"只是**交叉核对**，**不是判据**（判据是第 2 步两把门本身）。

### 4. `c_s` 与 `d` 判据

报 `A_joint` 下的 `c_s`、`Δc_s`（对 `A_F`）、以及
**`d = cz_robot − c_s_z` 的 `(0, 31.5) mm` 判据是否仍【恰好一支落在内】**
（`cz_robot` 取机械臂自报的 `68.699996948242188` mm）。这决定要下发的 `cz` 符号会不会翻。

### 5. 敏感性（如实报，不要挑好看的）

- 权重换一个**同样是先验合理**的口径（例如只用力通道、只用等权），结果怎么变？
- 逐姿态噪声换成"只留对角"这一简化，结果怎么变？
**若结论依赖权重选择，照实说** —— 那就意味着这条路不成立，而这是一个必须报的结果。

### 6. 判别力对照（必做）

同一套探针在 **15:33** 上跑（已知它是**（乙）**：λ 区间空集、`k=0.8~1.2` 全段空）。
若你的联合估计在 15:33 上也能让两把门通过，说明这个估计器**在把门"做松"**，
它在新数据上的"通过"就不算数 —— **停下并报告**。
