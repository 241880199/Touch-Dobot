1. **金标没有复现** —— 但原因不是实现回归, 也不是控制器读错了数, 而是

### 1.2 为什么不是"实现回归"

三份独立证据说明解析与代码都是对的, 差的只是那点精度:

1. **力通道的尺子逐位对上控制台**。控制台 run 003 的 dump 写着
   `力 σ_rep=0.0101/0.0117/0.0314 N (σ_sys=0.0000/0.0079/0.0061 N)`; 从夹具算出的
   σ_rep,F = `0.0101324 / 0.0117133 / 0.0313752` N, 反解出的 σ_sys,F = `~0 / 0.007834 / 0.006173` N
   —— 与打印的每一位都吻合。力通道的输入 (姿态 / 力 / N / sdF / 重复对下标) 因此是**逐字对的**。
2. **控制台的力门限 2.924 与夹具重放的 2.924170995 一致** (15:33)。
3. **控制台的措辞与本代码一致**: dump 里的
   `重复姿态对 (5 对, 每对取不同姿态时 = 尺子的自由度):` 逐字出自 `main.cpp:830`
   (commit `d043a66`)。所以控制台跑的就是这套代码。

### 1.3 真因: 夹具是**有损**记录

`calib_poses.txt` 把姿态写成 `%.1f`/`%.3f`、把 @1304 的力与力矩写成 `%.3f`
(`main.cpp:764-778`), 而控制台打印的是**内存里的全精度 double**。台阶与控制台的残差比:

| 量 | 文件台阶 q | 采集的残差/差值 | q 相对它 |
|---|---|---|---|
| 力矩 M1304 | 0.001 N·m | 拟合 rms 0.0019 N·m; 重复对差值 ~0.0002 N·m | **差值被 q 淹没** |
| 力 F1304 | 0.001 N | rms 0.015 N; 差值 ~0.005~0.05 N | 差值的 ~2~20% |
| 姿态角 | 0.1° | 重力方向 ~0.1° 就是 0.0017 rad → 4 N 上 0.007 N | 与 rmsF 同量级 |

力矩那一行是关键: 重复对的力矩差值本来只有 ~0.0002 N·m, 而文件只存到 0.001 N·m ——
**从夹具算出的 "回到同一个位姿的离散" σ_sys,M 几乎完全是量化噪声**:
夹具给 σ_rep,M,x = 0.000707, 控制台给 0.0005。而 σ_rep,M 进的是**分母**, 分母变粗 → 统计量变小。
15:33 的 33.74 对 61.22、15:25 的 6.97 对 5.359、15:30 的 18.36 对 20.51 —— 三个数的偏差
方向不完全一致, 是因为分子 (姿态量化 + 力矩量化) 也在动。

### 1.4 把这一点量出来 (一次性刮擦程序, **不在仓库里**)

`D:\tmp\mgscratch\round.cpp` (仓库外, 只作这次测量的出处)。做法: 把夹具里每个带小数的数按
它自己的台阶还原抽样一次 (`v + U(−q/2, +q/2)`, q = 0.1° / 0.001 / 0.001 N / 0.001 N·m / 1e-4),
再驱动生产 `fitRaw`; 每份夹具 400 次:

| 采集 | 统计量 (400 次) | 门限 (400 次) | 控制台值 | 落在还原区间 |
|---|---|---|---|---|
| 15:25 | [2.263, 19.96], 均值 7.487 | [5.319, 11.48], 均值 7.967 | 5.359 / 7.998 | **是** (统计量第 32.5 百分位) |
| 15:30 | [6.971, 45.15], 均值 18.12 | [5.08, 7.858], 均值 6.357 | 20.51 / 6.321 | **是** (第 72.2 百分位) |
| 15:33 | [14.18, 63.16], 均值 31.34 | [5.272, 8.649], 均值 6.912 | 61.22 / 5.239 | **是** (第 99.2 百分位; 门限 5.239 比区间下沿 5.272 低 0.6%, 400 次的最小值本身是噪声很大的次序统计量) |

**控制台那六个数全都落在"只把四舍五入丢掉的那一点补回去"所张开的范围之内。**
所以: 夹具重放与控制台打印**本来就是两个数**, 差多少由量化决定, 这两组数都"对"。
⇒ 金标这张表钉的是**夹具重放**的值 (可复现、可回归); 控制台那三个另存一列 (`conRatio/conLimit/conCond`),
**只打印、不断言**。任何"顺手把金标改成 5.359 让它对得上控制台"的动作都是错的。

### 1.5 容差

`RTOL_MG = 1e-6` (相对自身)。理由: 同一份夹具、同一个二进制走同一条确定性算术 → 逐位一致;
换编译器/libm 的差异经 12 参数正规方程放大约 1e-12 相对, 1e-6 宽出 6 个数量级。
反方向: 本用例要拦的每一类错 (统计量分母口径 / 失拟自由度 / σ_rep 池化 / 门限的 χ² 分位与折扣)
都会让这两个数动 ≥ 1e-2 相对 —— 比容差大四个数量级。

## 2. 零假设蒙特卡洛: 设置

- **驱动的是生产 `fitRaw`** (与实机路径逐字同参: 同一个 `PoseNoise`、同一串 `RepeatPair`、
  同一个 `MODEL_FORM_REQUIRED`)。**一个字都没有重推统计量或门限的公式** —— 控制器那份离线
  重写件 (4.95 / 13.36 / 11.06) 的教训就是这里。
- **"叉乘模型为真"是构造出来的**: 用该次采集**自己拟合出来的** `A`、`b_F`、`c_s`、`b_M`
  造 `F_i = b_F + A·g_i`、`M_i = b_M + c_s × (A·g_i)`。(被拒的两次也拿得到这几个数 ——
  头文件的契约写明 false 时 `out` 里是未经自检的线性解。)
- **噪声按夹具给的 (N, sd) 抽**: 逐一姿态均值的抖动按 `sd/√N` (即门限自己读到的 floor²),
  申报给 `fitRaw` 的也是 (n = N1304, var = sd²), 于是 **floor² 与真实抖动逐位一致**。
  (若直接按 sd 抽, 合成数据会比实机噪 √N ≈ 4.5 倍 —— 那是另一场实验。)
- **两套噪声模型, 都报** (免得结论挂在噪声模型上):
  - **A "brief 口径"**: 只有逐姿态噪声。"回到同一姿态再采一次"只差噪声, 尺子最细, 最保守。
  - **B "同复现性口径"**: A 之外, **每一次访问**再各自加一份 σ_sys 偏移 (逐通道),
    大小取该次采集**自己测出来的** `repeatSys[]`。实机上复位姿的离散是真有的,
    不放进来等于让尺子比现实细 —— 那会做出一个假的冤枉率。
    真实值大概率落在 A 与 B 之间 (A 没有 σ_sys; B 用的 σ_sys 又被夹具的量化抬高了)。
- **规模与耗时**: 3 采集 × 2 模型 × **2000 次 = 12000 次生产 `fitRaw`**, **1.0 s**
  (release, 单线程; `clock()` 计时, 由用例自己打印)。
- 噪声: 固定种子的 64 位 LCG + Box-Muller → 整个蒙特卡洛**逐次可复现** (两次独立运行计数完全一致)。
- 蒙特卡洛期间的 stderr 用 `_dup2` 接到 NUL (否则 12000 次判决会打出几万行), 跑完接回。

## 3. 冤枉率 (分开报)

**力矩分支** —— 分母是"走到力矩门的次数"(力通道一次都没拒, 所以几乎等于总次数)。
r = Σσ_sys²/Σfloor² 是门限自己读的那个比值 (由用例打印, 与 `modelFormLimit` 同一口径):

| 采集 | 对数 | r 力矩 | r 力 | 零假设 A | 零假设 B |
|---|---|---|---|---|---|
| 15:25 | 3 | 0.7685 | 0.5146 | **6.350%** (127/2000) | **21.922%** (438/1998) |
| 15:30 | 5 | 0.4058 | 0.8703 | **1.650%** (33/2000) | **4.500%** (90/2000) |
| 15:33 | 5 | 0.5301 | 0.08843 | **1.000%** (20/2000) | **0.900%** (18/2000) |

**力分支**: **0 / 12000**。唯一一次例外是 15:25 的 B 里 2 次 (0.100%)。
**其它自检** (质量尺度 / cond / 秩亏): **0 次**。

零分布统计量的形状 (均值 / 中位 / 90% / 99% / 最大) —— 门限 = 4.643 × factor, factor ≈ 1.0~1.6:

| 采集 | A | B |
|---|---|---|
| 15:25 | 2.553 / 2.101 / 4.84 / 8.729 / 13.71 | 5.309 / 3.87 / 11.05 / 23.84 / 49.24 |
| 15:30 | 1.923 / 1.614 / 3.693 / 5.908 / 10.52 | 2.541 / 2.005 / 4.973 / 9.379 / 16.86 |
| 15:33 | 1.782 / 1.505 / 3.325 / 5.843 / 10.19 | 1.846 / 1.516 / 3.628 / 6.185 / 14.49 |

**读法**: 门限是按 `χ²(6, 0.9999)/6 = 4.643` 再乘尺子的自由度折扣搭起来的, 也就是**假设零假设下
统计量的分布中心在 1**。实测分布中心是 **1.5~5.3** —— 门限那一刀因此切在零分布的**主体**上, 不是尾上。
这正是模块自己在头文件里备案过的近似 (A) (逐对截断在 0 + 同一个估量既当被估量又当折扣) 在
**力矩这条门**上的表现, 只是那里只量过力通道。同一个构造在力通道上 12000 次一次没拒 ——
说明病的**不是** `modelFormLimit` 的通式, 而是**力矩分支的分子** `ssM − ssFree` 在零假设下
不是 `6σ²` 的无偏估计 (它的回归量 w = A·g 带着 A 的估计误差, 自由 12 参数模型能把这份误差
吃掉一部分, 而受约束的叉乘结构吃不掉)。这个机制本报告只负责指出方向, **没有**去改它。

## 5. 我的读法

**两条都成立, 但它们解释的是不同的采集。**

- **(ii) 成立, 而且这是力矩这条门独有的事。** 在零假设 A 下 (门限读到的 floor² 与真实噪声
  逐位一致、且**完全没有**姿态间离散), 力矩门仍然拒掉 1.0%~6.4% 的正确模型数据;
  在零假设 B 下 (复现性与该次采集自己测到的一样) 是 0.9%~21.9%。同一次蒙特卡洛里
  **力通道 12000 次一次没拒**。也就是说: 力矩分支的统计量在零假设下的中心不在 1 (是 1.5~5.3),
  而门限仍按"中心在 1"来切。**这是门限的标定问题, 不是模型的问题。**
  R=3 的 15:25 最严重 (B 下 21.9%), 与模块头文件里那条"R 越小、残余冤枉率越大"的备案方向一致。
- **(i) 也成立, 对 15:30 与 15:33。** 这两次的实测值超出了**两套零假设里全部 2000 次抽样**,
  超出量还不小 (15:30: 18.36 对最大 10.52/16.86; 15:33: 33.74 对最大 10.19/14.49)。
  任何"仍然是检验"的门限都放不过它们 —— 把门限放宽到能过, 就等于把这条门关掉。
  自由 12 参数模型确实找到了叉乘结构解释不了的那一份。
- **15:25 站在另一侧**: 6.97 落在两套零分布之内 (96.6 / 76.2 百分位), 没有失拟的证据;
  它"通过"是正常的, 但它同时是**冤枉率最高**的那一次 —— 同一个采集既是"门限太紧"的证据,
  又(碰巧)没被拒。**姿态覆盖从 207 修到 18 的过程, 同时把 (ii) 摊开在了 15:25 上、
  把 (i) 暴露在了 15:30/15:33 上** —— 这就是那个反向相关的来源。
- **一个必须说的保留**: 夹具是有损的 (§1), 但量化的方向是**抬高力矩的尺子 σ_rep,M**,
  也就是**压低**统计量 (15:33 控制台的 61.22 在夹具上只剩 33.74)。所以"这两次连门限都够不着"
  这个结论在完整精度下只会**更强**, 不会更弱。量化本身给统计量加的项约 +0.3~0.6
  (6·σ_q²/σ_rep,a² 逐通道), 填不平 18.36 与 16.86 之间那 1.5。

**没有改任何阈值、任何模型、任何判决逻辑。** 门限该不该动、力矩模型该怎么补 (还是接受一个
经验模型), 是用户自己的决定。
