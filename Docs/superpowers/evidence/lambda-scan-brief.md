# Task brief — λ 扫描：这一份力矩拒绝属于哪一类

## 背景（已确立，不要重推）

力矩通道的失拟检验（`fitRaw` 的 `lackOfFitMomentRatio`）拒绝时，有两种**性质完全不同**的原因：

- **(甲) `A` 估得差** —— 力矩模型复用的是**力通道估出来的 `A`**，而力矩通道想要的是另一个 `A_m`。
  这时存在一个 `A(λ) = A_F + λ·D` 能**同时**满足两把门。
- **(乙) 两条通道真矛盾** —— 任何 `λ` 都做不到两边同时通过。

**已实测的三次采集**（见 `Docs/superpowers/evidence/moment-model-structure-report.md` §7）：

```
15:25   λ ∈ [0, 1]         (甲)
15:30   λ ∈ [0.47, 1]      (甲)
15:33   空集                (乙)  最好折中 λ=0.5 时两侧各超限 1.45~1.49 倍
```

`λ=1` 时的两把门一起看（15:25/15:30/15:33）：

| | 力通道统计量（门限 4.16/4.37/2.92） | 力矩失拟（门限 7.40/6.05/6.44） |
|---|---|---|
| `A_F`（λ=0） | 1.46 / 1.02 / 1.38 | 6.97 / 18.36 / 33.74 |
| `A_hybrid`（λ=1） | 2.05 ✓ / 3.31 ✓ / 13.25 ✗ | 0.68 / 0.82 / 1.12 |

**`D = P(A_m − A_F)`** 的构造：`B_free ≈ [c]ₓ·A_m`，而 `[c]ₓ·A_m` 的每一列都 ⊥ `c`，
所以 `Bᵀc = 0` ⇒ **`c` 的方向就是 `B_freeᵀ` 的零向量**；给定 `c` 后解 `[c]ₓA_m = B_free` 得 `A_m`；
`P` 是规范投影（`A` 沿 `c` 的分量力矩方程看不见，`[c]ₓ·(c·vᵀ) = 0`）。
**规范处理必须与上一份报告逐字一致**，否则 λ 区间不可比。
