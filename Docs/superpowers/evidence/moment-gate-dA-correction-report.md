## 0. 结论(先说)

1. **闭式【不成立】—— 但差的不是量级, 是"取哪一项"**。提案写的那个量
   `E[Σ‖sym([c]ₓΔÂ⁻¹)z‖²]` **系统性偏大 1.49~2.97 倍**,而且这个倍数**随 `cond` 单调**
   (cond 206.6 → ×2.97/×2.85;cond 43.9 → ×2.34/×2.61;cond 18.2 → ×1.49/×1.56)。
   **不可以用一个拟合常数救它** —— 跨采集变化 2 倍,常数在 15:33 上会差一倍。
   原因正是提案自己列出的疑点 1:受约束模型的最优 `c'` **不是** `T` 的反对称部分,
   最小二乘会再用剩下 3 个自由度把 `sym(T)` 里能被反对称族吃掉的那一份也吃掉。
2. **把"重优化"写进去之后,机理被钉死到 0.3% 以内**。用**那一次真实的 Δ** 算
   `min_p Σ_a Σ_i ((T−[p]ₓ)z_i)_a²/σ_rep,M,a² / 6`(受约束模型的完整最小二乘重优化),
   六格与实测的 δA 去掉量之比是 **0.997 / 1.001 / 1.003 / 0.998 / 1.004 / 1.002**。
   ⇒ errors-in-variables 的机理链**完全正确**,只是提案漏了"重优化"这一步。
3. **光滑闭式(用生产能造出的 Σ_A 做期望)仍差 9~23%**(六格比值 0.825/0.768/1.103/1.124/
   1.132/1.154)。差的那一份我定位到了分母:`σ_rep,M²` 自己是从 R 对重复姿态差里估出来的
   **截断**估量,`E[1/σ²] > 1/E[σ²]` 的 Jensen 项很大(逐次预测 vs 定值预测差 2.5~7.3 倍)。
   **这一项我没有闭环**,见 §6.2。
4. **"Σ_A 生产已经在算了" 这句不成立**。产出 `paramSigma` 的那个 `s2F = ssF/(3n−12)` 是
   **三通道池化**的,而实机力噪声三通道差 4~5 倍(夹具 sdF1304 = 0.053/0.034/0.131 N)。
   于是 `paramSigma` 把安静的 x 通道的 A 不确定度**高估 2.5 倍**、把 z 通道**低估 1.3 倍**,
   拿它做修正量会**放大 6 倍**(§4.3)。正确的 Σ_A 是**三明治** `(JᵀJ)⁻¹JᵀΣJ(JᵀJ)⁻¹`,
   用 `noiseIn`(生产已经有)就能造,与蒙卡实测的 Δ 协方差**逐通道吻合到 0.5%**。
5. **D2: 修正后的冤枉率 0.58%~3.48%(A) / 0.59%~10.68%(B)** —— 比基线好一半左右,
   **但离 δA 去掉后的 0.03%~1.08% 还差得远**。因为**减均值减不掉"散布"**:δA 引起的额外量
   自身 sd 就有 0.72~1.09(它自己的均值才 0.79~1.29,变异系数 ~0.9),修正后零分布的 sd
   是 δA=0 那一个的 **1.5~3.1 倍**。疑点 2 的答案是 **"是,残余散布仍然要紧"**,
   门限还得再放宽 **约 1.3~1.9 倍**才谈得上 α=1e-4。
6. **D3: 三次实机判决【全部保住】**(6 个格 = 3 采集 × 2 噪声模型,三个修正变体都保住了)。
   15:30 的修正后值 16.96~17.88 对门限 6.05(2.8 倍余量);15:33 是 33.11~33.26 对 6.44
   (5.2 倍)。**"15:30 与 15:33 落在全部零假设抽样之外"这条结论是安全的。**

  用**三明治 Σ_A**。含 9 个基方向的数值核 + `M⁻¹`,构造与解析式交叉验证到 1.5e-16。

### 2.1 提案原式为什么偏大(疑点 1 的答案)

把 `T = [c]ₓΔÂ⁻¹` 拆成反对称 `Ω` + 对称 `S` 之后,受约束族能表示的是整个反对称族,
所以"最优 `c'`"= `p_Ω + q*`,而 `q*` 由法方程 `M q* = Σ_i [z_i]ₓ S z_i`
(`M = Σ_i(‖z_i‖²I − z_i z_iᵀ)`)定。于是

```
f_min(Δ) = Σ_i‖S z_i‖² − (q*)ᵀ M (q*)
```

**提案只算了第一项。** 第二项在六格上是第一项的 **0.13 ~ 3.05 倍**(`H(q)` 项实测:
2.78 / 1.10 / 0.29 对 `G(sym)` 项 3.85 / 2.08 / 1.17),它一点也不小。

**这个近似什么时候坏**:`q*` 是被 `z_i` 的几何张成的自由度,而 `z_i` 张得好不好正是 `cond`
量的东西。实测倍率与 `cond` 严格同向:

| 采集 | cond | ①/实测(A) | ①/实测(B) |
|---|---|---|---|
| 15:25 | **206.6** | **2.967** | **2.853** |
| 15:30 | 43.9 | 2.339 | 2.608 |
| 15:33 | **18.2** | **1.495** | **1.558** |

⇒ **提案那条近似在姿态铺得最差的采集上错 3 倍,在铺得最好的上错 1.5 倍。**

### 2.2 拟合常数可不可用 —— **不可用**

跨采集 1.49~2.97,变化 **2 倍**;同采集跨噪声模型 A↔B 只差 4%~11%。也就是说
"一个常数"只对**一次采集**成立,换一份姿态就错一倍。**明确说:拟合常数不可接受。**
(而且它随 `cond` 单调,真要拟合得拟合成 `cond` 的函数 —— 那就不是修正常数,是另一套模型。)

## 3. 修正量怎么算(给实现的说明)

两个候选量都只需要 `RawFit` 现有字段 + 姿态,代价可忽略。

**Σ_A(生产应当用的那一个)**:`Cov(Â) = (JᵀJ)⁻¹ JᵀΣJ (JᵀJ)⁻¹`,其中 Σ 是**逐姿态逐通道的
均值噪声方差** `noiseIn[i].varF[a]/noiseIn[i].n`(变体 B 再加 σ_sys²)。
`JᵀJ` 逐通道块对角,所以 A 的 3×3 块 = `σ_a²_eff · H⁻¹`,`H = Σ_i(g_i−ḡ)(g_i−ḡ)ᵀ`。
**与蒙卡实测 Δ 的对照:**

| 采集 | 逐通道 sd: 经验 / 三明治 / 池化 `paramSigma` |
|---|---|
| 15:25 | 0.006767 / **0.0067768** / 0.016686 ・ 0.0054938 / **0.0054988** / 0.016686 ・ 0.021937 / **0.021930** / 0.016686 |
| 15:30 | 0.0034484 / **0.0034541** / 0.0077618 ・ 0.0026381 / **0.0026437** / 0.0077618 ・ 0.010067 / **0.010057** / 0.0077618 |
| 15:33 | 0.0015367 / **0.001544** / 0.0030309 ・ 0.0013795 / **0.001380** / 0.0030309 ・ 0.0047445 / **0.0047462** / 0.0030309 |

- **三明治造法逐通道吻合到 0.5% 以内**(|δA|_rms: 0.030307↔0.030313, 0.036462↔0.036487,
  0.014159↔0.014167, 0.019390↔0.019384, 0.007069↔0.007059, 0.007375↔0.007378)。
- **池化 `paramSigma` 不是 Σ_A**:它对三通道给同一个数(`s2F·(H⁻¹)`),而实机力噪声三通道
  差 4~5 倍(夹具 sdF1304 = 0.053 / 0.034 / 0.131 N)。逐通道误差:15:25 的 a=0 高估
  **×2.47**、a=2 低估 **×0.76**;15:30 ×2.25 / ×0.77;15:33 ×1.97 / ×0.64。
  |δA|_rms 只在 1.01~1.24 倍上,是因为三通道误差在求和里互相抵消 —— **逐通道看才是真错。**

**两个可落地的算式**(都在 §2 的 ③ 里量过):

- `predLoF = Σ_a [ quadr(G_a, Σ_A) − quadr(H_a, Σ_A) ] / σ_rep,M,a²`
  其中 `G_a[p][q] = Σ_i (S_p z_i)_a(S_q z_i)_a`,`H_a[p][q] = Σ_i (q_p×z_i)_a(q_q×z_i)_a`,
  `S_p`/`q_p` 是 Δ 取 9 个基方向时的 `sym([c]ₓΔÂ⁻¹)` 与重优化量(9 次 3×3 求值即可)。
  修正后的统计量 `S' = max(0, S − predLoF/6)`,**门限不动**。
- 或者只要"提案的口径"(不写重优化):`predLoF = Σ_a quadr(G_a, Σ_A)/σ_a²`。

**运行时代价**:9 个基方向 × (一次 3×3 乘 + n 次 3-向量运算) ≈ 2×10³ flops,
加 2×81 的二次型,再两次 3×3 求逆;而 `fitRaw` 自己那两次 Gauss-Jordan(12×12 与 6×6)
≈ 4×10³ flops。**修正在一次标定里的总代价是亚毫秒级**,实测端到端 50 µs/次(200k 次
2.4 M `fitRaw` 用 120 s),而诊断探针不带修正时是 48.6 µs/次 —— **量不出来**。

### 4.2 读法

1. **比基线好,但远远不到 δA 去掉的水平。** 修正只抹掉了基线冤枉率的 **50%~64%**,
   而 δA 去掉抹掉的是 92%~98%。(15:25/B 仍是 **10.68%**,那是最坏的一格。)
2. **原因不是"均值没修正够"(这个只有 9%~23%),是"散布减不掉"。** δA 引起的额外量本身
   `sd = 0.72 ~ 1.09`,而它自己的均值才 `0.79 ~ 1.29` —— 变异系数 ~0.9,是个**重尾的正量**
   (平方型)。减掉条件均值之后,残余 sd 是 δA=0 那一个的 **1.5~3.1 倍**
   (15:25/A 1.72 vs 0.95;B 4.02 vs 1.30)。**疑点 2 的答案是"是,残余散布仍然要紧"。**
3. **sym-only 那一列冤枉率更低(0.25%~2.37%)—— 那是"两个错凑一个对"**:它把均值
   超减了 1.5~3 倍,正好用超减的那部分抵消了残余散布。它的代价在 D3 里看得出来
   (15:25/B 的修正后统计量塌到 0),**不能当成它更准**。

## 5. D3 —— ★ 三次实机判决的保全检查

夹具 `Touch_Client/tests/fixtures/calib_poses_2026-09-19_15*.txt`,按既有测试逐字解析

## 6. 没能钉死的部分(诚实清单)

### 6.1 光滑闭式还差 9%~23%

§2 的 ③ 列(三明治 Σ_A 下、**逐次**用 `fit.repeatSigmaM` 的期望)对实测:
1.0715/1.29411 = 0.825、2.84462/3.70642 = 0.768、0.983438/0.893759 = 1.103、
1.63552/1.45261 = 1.124、0.888818/0.787797 = 1.132、0.714052/0.620394 = 1.154。
**六个格两个方向都有(15:25 偏低,15:30/15:33 偏高)。**

我已经定位到两处可疑,但**没有闭环**:

1. **`q*` 那一项的二次型有 ~9% 的系统偏差。** 单独比:实测 `E[qterm] = 2.783 / 1.104 /
   0.288`,闭式 `quadr(H, Σ_A)/σ² = 2.78 / 1.27 / 0.158`(对应 15:25/15:30/15:33 的 A)。
   而且代数恒等式 `fsym − fmin = q*ᵀMq*` 在数值上**只满足到 12%~24%**(
   `M = Σ(‖z_i‖²I − z_iz_iᵀ)` 在姿态张成一个薄锥时条件数很坏,`M⁻¹` 掉精度是最大嫌疑)。
   **这一步我只做了量级核对,没有做逐位代数验证。**
2. **`σ_rep,M²` 的 Jensen 项很大,而且是"用哪个 σ"决定一切。** 同一个闭式:
   - 用**实机那一次**的 σ(定值)去算:15:25 的 `G(sym)=1.82015`、`H(q)=1.26084`、
     `精确=0.559315`;
   - 用**逐次**的 σ 去算(生产会这样做):`G(sym)=3.85493`、`H(q)=2.783`、`精确=1.0715`。
   **差 2.5~6.9 倍**,方向是 `E[1/σ²] >> 1/E[σ²]`。所以 §2③ 里我把"逐次"和"实测"放在
   同一口径下比是必需的;**任何"用一次实测的 σ 去代表分布"的算法都会错上数倍**。
   为什么 `σ_rep,M` 的倒数这么重尾:`repeatSysM = mean_j max((d_j² − 2·floor)/2, 0)`
   里那个 `max(·,0)` 让它在 0 上有一个原子(头文件"已知近似 (A)"说的就是它),
   加上夹具的量化,`σ_rep,M` 可以小到 `floor`。

**这两条都只影响"闭式的精度",不影响 §2② 那条结论**(精确重优化在真 Δ 上 0.997~1.004)。

### 6.2 其它

- 本探针**没有**去动 `PayloadCalibration.*` / 门限 / 判决逻辑,也**没有**跑任何别的 exe,
  没有碰机械臂。`Touch_Client.exe` 未被干扰。
- 蒙卡的"真值"用的是该次采集**自己拟合出来的** A / b_F / c_s / b_M(与既有测试同口径)。
  所以"叉乘模型为真"是构造的,不是假设的。
- 实机那三次的 A 是从**夹具**(3 位小数)解出来的;控制台是全精度 double。所以 §5 的
  predS 也带着同一份量化误差。这不改变"判决保全"的结论(余量 1.6~5.2 倍),
  但严格地说,predS 的绝对值只在夹具重放这一口径上成立。

## 7. D4 —— 建议与代价

### 7.1 建议

**(1) 提案原样(sym-only 闭式)不要进生产。**
它偏大 1.49~2.97 倍,且倍数**跟着 `cond` 走**(cond 207→×2.97,cond 18→×1.50)。
它的"好用"(D2 冤枉率 0.25%~2.37%)是**超减**换来的,机制是错的,换一份姿态覆盖率就
不成立;拟合常数也救不了(跨采集变 2 倍)。**明确:拟合常数不可接受。**

**(2) 如果要做统计量级的修正,进生产的是"精确重优化"那一版:**
`predLoF = Σ_a [ quadr(G_a, Σ_A) − quadr(H_a, Σ_A) ] / σ_rep,M,a²`,Σ_A 用**三明治**
(生产用 `noiseIn` 就能造,`paramSigma` **不能**用 —— 它是三通道池化的)。
- 机理:在真 Δ 上六格吻合到 **0.997~1.004**;这是唯一把"受约束模型会重新优化 `c'`"
  写对的版本。
- 代价:**运行时亚毫秒级**(≈2×10³ flops,不到 `fitRaw` 自身两次正规方程求逆的一半;
  实测端到端 50 µs/次 vs 无修正 48.6 µs/次,**测不出来**)。要动的是
  `RawFit`/`fitRawLinear` 里加一个诊断字段与一个纯函数,**不改任何门限、不改判决路径**。
- **但它只解决一半**:冤枉率 0.58%~3.48%(A) / 0.59%~10.68%(B),对 δA=0 的
  0.03%~1.08% 还差一截。**必须与"门限再放宽 ~1.3~1.9 倍"配套**,否则等于没修。

**(3) 我的实际推荐:先别动统计量,动门限。**
理由:诊断报告已经证明力矩门的病**主要是"门限切在零分布的主体上"**(其 §4.3:`modelFormLimit`
给的门限**低于零分布的 99% 分位**),而**减去一个重尾正量的均值减不掉它的散布**(§4.2)。
在"统计量中心 1.5~5.3、门限按中心 1 切"这件事上,最直接、最便宜、最可验证的一刀是
**把力矩门限乘一个实测因子**(用每台设备自己的重复对,把门限放到实测零分布的 99.9% 附近)。
代价:门变松 —— 但既有证据说这个代价很小:三条错误模型的余量表在 26~400 倍
(`PayloadCalibration.h` 上面的注释),15:30/15:33 在修正后仍有 2.8 倍 / 5.2 倍余量。

**(4) 无论选哪条,先把 `paramSigma` 的池化口径记一笔**:它的逐通道误差达 ×2.5 / ×0.76,
凡是"拿 `paramSigma` 当 A 的不确定度"的地方(不只是这个修正)都受影响。

### 7.2 我没能验证的

1. **光滑闭式那 9%~23% 的来源没有闭环。** 方向定位到了(`q*` 项的二次型偏差 ~9% +
   `1/σ_rep,M²` 的 Jensen 项),但两条都没有做逐位验证。**在闭环之前,"精确闭式进生产"的
   修正量会有 ±20% 的误差** —— 好在这个误差远小于提案原式的 ×1.5~3.0。
2. **门限该放宽到多少,本报告只给了"修正后零分布的 99.9% 分位 / 现行门限"这个比值
   (1.3~1.9 倍)**,没有去设计那个门限的构造(那属于改门限,不在本任务内)。
3. **没有在真实的全精度数据上验证过** —— 全部数字都建在冻结夹具上,夹具把力矩量化到
   0.001 N·m(见 §5 的 ⚠)。**判决保全的结论在完整精度下只会更强,但修正量的绝对值会动。**
4. **`cond` 与 sym 近似误差的关系只用了 3 个点**(206.6/43.9/18.2),拟合不出函数形式;
   样本只有三次采集。
