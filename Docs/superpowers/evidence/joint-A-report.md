## 3. 主估计器 —— 构造与权重（先定死，再看门）

**把力方程与力矩方程放进同一个加权最小二乘**：

```
θ = [ b_F(3) | vec A(9) | b_M(3) | c_s(3) ]            18 个未知量, vec A 行主序

χ²(θ) = Σ_i Σ_a ( F_ia − b_Fa − (A g_i)_a )² / s²_F,ia
      + Σ_i Σ_a ( M_ia − b_Ma − (c_s × (A g_i))_a )² / s²_M,ia

s²_F,ia = varF_ia / N_i ,  s²_M,ia = varM_ia / N_i      <- §2 的实测噪声, 逐姿态逐通道
g_i = TcpCalibration::gravitySensorFrameAtYaw(pose_i, 0.0, ·)
```

**为什么是它**：brief §1 第一段就是这句"放进同一个加权最小二乘，未知量 `(b_F, A, b_M, c_s)`"。
`M = b_M + c_s ×(A g)` 对 `(c_s, A)` 双线性 ⇒ 非线性最小二乘。
权重的**唯一**来源是 §2 的实测逐姿态噪声（因此 `A` 的人一列"信噪"由数据自己定，
不由 `paramSigma` 那类池化口径定）；这一步**在看任何门的数值之前就写死了**。

**求解**：Gauss–Newton，**解析 Jacobian** + 阻尼步长搜索：

```
∂(F−…)/∂b_Fa = e_a            ∂/∂A[a'·3+c] = e_a g_c
∂(M−…)/∂b_Ma = e_a            ∂(c_s×w)_a/∂c_s,k = (e_k × w)_a = crossMatK(w)
                              ∂(c_s×w)_a/∂A[a'·3+c] = (c_s × e_{a'})_a · g_c
```

### 7.1 敏感性到底影响了什么 —— 照实说

- **结论依赖权重选择，但依赖的是"用不用实测噪声"，不是"用哪一种实测噪声"。**
  `[S1]/[S2]/[S5]`（不用力矩噪声、或等权）拒绝力矩门 —— 那正是 brief 明令不许的口径
  （它们把"力矩通道的实测噪声"整个丢掉了）。凡是**用实测噪声加权力矩通道**的口径
  （主估计器、`[S3]`、`[S4]`、`[S6b]`）**都让两把门接受**。
- **但"接受"是贴线的，不是稳的**，两处证据：
  1. `[S3]`（逐姿态噪声简化成逐通道一个值）力矩门 4.810 / 4.909，**只剩 2.0% 余量**；
     力矩块权重只要减半（k=2）就翻。

## 9. 没能验证的地方 / 口径的边界（诚实清单）

1. **brief §1 有两种同样合理的读法，它们判决相反**，我没有办法从文本定死是哪一种：
   - **读法一（我按 a priori 选的主估计器）**："把两个通道的方程放进同一个加权最小二乘"，
     每个方程的权重 = 该方程自己的实测噪声 ⇒ §4 的**两把门接受**。
   - **读法二**："力通道的 `Cov(A_F)` 用 sandwich、力矩侧传播 `Cov(B_free)`"，即把两个通道
     各自的估计按协方差矩阵加权融合 ⇒ **拒绝力矩门 1.4%**。
     两者的差别在"给力通道多大精度"：融合用的是 **A_F 的（未加权 OLS 的）sandwich**，
     它比加权解的精度略低，于是力矩侧相对更重，λ 从 0.684 退到 0.619 —— 而门限在 0.6226。
     **我没有把这两者调和，也不认为该调和**：这是"判决贴着门"的直接证据（§7.1）。
2. **`A_joint` 的两把门数值来自这份复算件，不是生产 `fitRaw` 直接吐出来的** ——
   生产只对它自己解出的 `A` 报统计量。等价性在 λ=0 上验到 1e-14（§1），但没有生产侧的第二来源。
   `[S6]` 的融合值同样只来自复算件。
3. **`[S6]` 融合把 `c_s` 固定在 `A_F` 的受约束拟合值上**（brief 说的"经 `[c]ₓ·A_m = B_free` solve"
   本来就是把 `c` 当已知），这是个线性化；精确做法要对 `c_s` 边缘化，那就是主估计器在做的事。
   所以 `[S6]` 那 1.4% 的超限里有多少是这条近似带来的，**我没有量化**。
4. **门限端点/统计量的绝对位数**按打印位数读没有意义（数据本身只有 3 位/9 位小数），
