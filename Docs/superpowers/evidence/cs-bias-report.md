## 2. Q1 —— `Δc_s = c_s^(b) − c_s^(a)`

### 2.1 记号与**规范约定**(必须先说清楚)

- **(a)** 生产: 用 `A_F` 解 `M = b_M + c_s × (A_F·g)` → `c_s^(a)` = `RawFit::cS`。
- **(b)** 用**力矩通道偏好的** `A_m` 解同一个式子 → `c_s^(b)`。
  `A_m` 按上一次报告的构造取**最小范数解**: `A_m(c_ref) := −[c_ref·ĉ]ₓ·B_g / c_ref²`,
  其中 `B_g` = 自由力矩拟合 `M = b + B·g` 的 9 个系数, `ĉ` = `B_g` 单位左零向量
  (`‖B_gᵀĉ‖ = σ_min`, §1.2 验证)。
- **规范自由度**: 力矩通道只看得见乘积 `[c]ₓ·A = B_g`, 该方程的解集是 `(c, A) → (λc, A/λ)`
  **以及** `A → A + c·vᵀ`(3 参数, 我实测**对 `c_s^(b)` 完全无影响**: 变 ‖A_m‖_F = 0.0032 只让
  `c_s^(b)` 动 0.000~0.006 mm)。所以**规范就是一个标量 `c_ref`**, 而 `c_ref` **恰好就是 `c_s^(b)` 的长度**:

  > 喂 `A_m(c_ref)`, 受约束拟合的极小点就是 **`c_s^(b) = c_ref·ĉ`**(到 σ_min 级;实测
  > `ss(c_ref·ĉ)` = 1.8024e-5 vs QR 拟合的极小 1.8003e-5 vs ssFree 1.7866e-5, 12:38)。

  **我固定的约定(主口径): `c_ref = |c_s^(a)|`。** 理由: 它让 `Δc_s` **只反映方向变化**,
  也就是**力矩通道真正决定得了**的那一份;长度那一份是规范, 不能借它下结论。
- **物理口径(参考)**: `|c| = |p|/m`, `|p|` 从 `B_g` 的奇异值读、`m = (σ1σ2σ3)^(1/3)(A_F)` 从力通道读。

- ⇒ **"`Δc_s` 在 0.5~1.4 mm"这条结论站在量化底板之上 3~10 倍**, 成立;
  但**再往下切到 0.1 mm 就没有意义了**。15:30 的 0.85 mm 是最薄的一格。

## 4. Q3 —— `A_m ≠ A_F` 能解释采集间散布吗

### 4.1 同向性检验(最直接的一个测试)

若散布主要来自 `A` 的偏差, 那么 `c_s^(a)` 相对均值的偏差应当 ≈ **−`Δc_s`**(符号相反、同向)。
逐采集(主口径, mm):

| 采集 | 偏差 dev = `c_s^(a)` − 均值 | `|dev|` | `Δc_s` | `|Δc_s|` | **cos(dev, Δc_s)** | `|dev|/|Δc_s|` |
|---|---|---|---|---|---|---|
| 12:38 | (+0.5247, −0.3051, −0.6521) | 0.8908 | (−0.0409, −0.5074, −0.0065) | 0.5091 | **+0.303** | 1.75 |
| 15:25 | (−0.3394, +0.6192, +0.3437) | 0.7853 | (+0.2714, −1.3226, +0.0046) | 1.3502 | **−0.858** | 0.58 |
| 15:30 | (−0.4711, −0.2060, +0.8354) | 0.9810 | (+0.8183, −0.2299, −0.0010) | 0.8500 | **−0.407** | 1.15 |
| 15:33 | (+0.2859, −0.1081, −0.5271) | 0.6093 | (+1.1335, +0.4423, −0.0185) | 1.2169 | **+0.386** | 0.50 |

- **余弦符号翻**(两次正、两次负), 加权平均 −0.27;最优比例 **α = −0.19**(几乎为零)。
  只有 15:25 一次像样(−0.86)。
- **最好情况下的解释力**(在规范上扫描, 见下): **幅值匹配规范(λ=1)只解释 15%**;
  整个 λ∈[0.9,1.1] 里最小残差分数 **0.471(λ≈0.98, 事后挑的)** ⇒ **最多解释 53%**。
  残差分数逐格: 0.90:0.595 0.92:0.575 0.94:0.546 0.96:0.499 **0.98:0.471** 0.99:0.582
  **1.00:0.854** 1.02:0.901 1.05:0.810 1.10:0.752。
- ⇒ **结论: 同量级, 但不是同一个东西。** `A_m/A_F` 之差(0.5~1.4 mm 横向)与散布
  (横向 rms 0.55 mm)确实是一个量级, 但它**不跟着散布走**, 所以**不能拿它解释这次的四次采集**;
  它是**叠在散布之上的、独立的、同量级的一份**。

### 4.2 散布长什么样(不许猜, 只报量出来的)

1. **方向 vs 长度**: 四次 `c_s` 的**方向**很稳(`ĉ` 两两夹角 0.33°~1.32°),
   而 **`|c_s|` 自己散 1.29%**。散布的方向分解是 **径向 0.615 / 横向 0.554 mm**(四六开)。
   ⇒ 一半是靠"长度"散的。
2. **"长度"不是质量尺度来的**: `m·c_z`(一阶矩 `p_z`, 力矩通道自己的量)
   `sd = 1.15%`, 而 `sd(m)/m = 0.54%`。由 `c_z = p_z/m`,
   `Var(c_z)/c_z² ≈ Var(p)/p² + Var(m)/m²` 得 `1.29%² ≈ 1.15%² + 0.54%²`
   ⇒ **质量尺度只占 z 方差的一成八, 剩下八成都写在力矩数据自己的 `p_z` 里。**
   (与 §3.2 的 A-only 那一列比: 力通道误差能挪动 `c_s` 0.07~0.27 mm, 小于散布。)
3. **力矩通道偏好的方向并不更稳**: `ĉ_null` 的两两夹角是 0.53°~1.53°, 与 `c_s^(a)` 的
   0.33°~1.32° **同一档**。⇒ **"换成 `A_m` 就会更一致"这个说法不成立。**
4. **相关性(n=4, `|r|` 要过 ~0.95 才值得看一眼)**:

   | 与 `c_z` 的相关 | r | | 与 `c_z` 的相关 | r |

   | 各向异性比 σ1/σ3(A_F) | **+0.9924** | | 采集时刻 | +0.5926 |
   | `‖E‖_F / ‖B_g‖` | +0.8168 | | 姿态数 | +0.5341 |

   的估计误差**, 而 `A_F` 的估计误差又与姿态覆盖有关。

## 5. Q4 —— 给机械臂的底线

下一个消费方是 Dobot CR3 的 `(weight, cx, cy, cz)`(mm)。现在能说的是:

**(1) 现在 `c_s` 的不确定度是多少**

| 口径 | 数值 |
|---|---|
| 单次采集的 1σ(生产自报, 每分量) | 0.16 ~ 0.48 mm(rms 0.25 ~ 0.39 mm) |
| 把 `A_F` 误差 + 实测姿态间复现性都算进去的单次 1σ(MC) | 0.09 ~ 0.40 mm 每分量(rms 0.12 ~ 0.34) |
| `A_m/A_F` 之差对 `c_s` 的推动(方向那一份, 规范无关) | **0.51 / 1.35 / 0.85 / 1.22 mm** |
| 同上, 长度那一份 | 0 ~ 3.4 mm(取决于规范; 物理口径下 0.16 ~ 3.36 mm) |
| **四次采集之间的散布** | **sd 0.48 / 0.42 / 0.71 mm;`|c|` sd 0.71 mm;极差 1.00 / 0.92 / 1.49 mm** |

**该按 ±1.5 mm 报(四次极差), 1σ 按 0.7~0.9 mm 报。**
若只允许取一个数给下游: **`|c_s|` 的不确定度 ≈ 0.7 mm (1σ) / 1.5 mm (全范围)**,
分量上 `c_x,c_y` 各约 0.4~0.5 mm、`c_z` 约 0.7 mm。

**(2) 主导项**

主导的是 **(ii) 采集间散布**, 不是 (i), 也不是 (iii):

- (i) `A_m/A_F` 之差**尺寸上不小**(4~10 倍于单次 σ;与散布同量级), 但它**不跟散布同向**
  (cos +0.30/−0.86/−0.41/+0.39;最优 α = −0.19;幅值匹配规范下只解释 15%, 全规范最好 53%)。
  ⇒ 它是**叠在散布上的另一份同量级不确定度**, 不是散布的成因。**它不该被减掉**(没有稳定方向, 事实 4),
  但也**不能被忽略**: 它给"把 `c_s` 采得更准"这件事设了一个模型层的底板。
- (ii) **散布是主导项, 而且它比上面任何一条单次不确定度都大**: 1.9~2.3 倍于自报 σ、3.9 倍于极差,
  最坏一对差 3.9σ。四次采集里三次(15:xx)是**同一套协议、同一套姿态**, 所以这不是"采集做错了",
  是**这套设备在姿态之间就复现不到 1 mm 以内**。
- (iii) 残余: z 的散布**不来自质量尺度**(只占一成八), 它写在**一阶矩 `p_z` 自己**身上(§4.2)。
  `p_z` 是力矩通道的直接产物, 所以这一份只能靠**改采集**(更多/更好的姿态覆盖、更长的样本窗、
  或有朝一日修模型)去压, 不是标定能修的。四个点指不出具体机制。

**(3) 它与"坐标系/原点"那个已知未决问题是可分的吗**

- **与 `A_m/A_F` 的比较: 完全可分。** (a) 与 (b) 用的是**同一批力矩、同一批姿态、同一个原点约定**,
  两者相减, 任何**共同的**原点偏移都消掉。⇒ **第 2 节的 `Δc_s` 一点不受原点问题影响。**
- **与采集间散布: 一阶可分。** 四次的散布是**差**;一个**共同的**原点偏移在四次里是共模的, 会抵消。
- **但"完全可分"要打个折**: 原点错不是纯粹的事后平移 —— 它在数据里表现为 `δ × (A·g)` 这一项,
  是**姿态相关**的, 会被拟合**吸收进 `c_s`**, 吸收多少取决于姿态集合。四次的姿态集合不同
  (7 / 9 / 10 / 10), 所以这一份**有一小部分会漏进散布**。
  这四份数据**分不开**"原点漏进来的那一份"和"设备复现性的那一份" —— 要分开得另做实验
  (同一姿态集、两组原点约定)。**本报告的 `Δc_s` 不受这个影响**(它是同一次采集内部的两解之差)。

**(4) 一次也没有碰**: 绝对 `c_s` 的**含义**(从哪个点量、`comSignZ` 取哪个符号)本报告一个字都没动。
