# Task brief — 上机结果自动记录成文档

## 要解决的问题

上机的记录现在是**人肉转录**的。`Docs/superpowers/specs/2026-09-19-raw-channel-calibration-run-001.md`
这类文件的结构是：

```
# 标题 / 日期 / 分支 / 代码 / 模式 / 姿态数
## 1. 结论先行  (表格)
## 2. 尺子明细 / 逐姿态残差 / 解出的模型
## 6. 本次什么也没应用
---
## 附: 原始控制台输出（逐字保留）      ← ← ← 这一节是核心, 而且完全是手抄的
```

控制台会滚掉；`calib_log.txt` 只记 22 个窄列；`calib_poses.txt` 只记原始数据。
**没有一处留下"操作员当时看到的整屏"。**

## 要做的

**让 `'s'` 求解时把整屏诊断【同时】写进一份 Markdown 文档**，使上面那个"附"节能自动产出。

### 硬要求

1. **一个 sink，两处输出。** 控制台与该文档必须**逐字节同源** —— 不要"再打印一遍到文件"
   （那会让两者漂移，而本项目的验收判据之一恰恰是**控制台与落盘必须一致**）。
   实现方式自行选择（例如一个同时写 `stdout` 与文件的 writer，替换求解路径上的打印调用），
   **但"同源"是可验收的**：跑一次 `'s'`，文档里那一块与屏幕上的必须一致。
2. **文件**：`CalibStore::fileFor("calib_report.md")`
   （即 `Touch_Client/calib/calib_report.md`，与另两份日志同址）。
3. **只追加，永不截断。** 打开方式**必须**是 `"a+"`，**绝不能**先试 `"r"` 再决定 `"w"`/`"a"`。
   理由与 `logCalibAttempt` 里那段注释逐字相同（`main.cpp:634-636`）："读不了"(被占用/权限) 与
   "不存在"会被混为一谈，而前者会走 `"w"` 把历次记录整个删掉。**这条没有例外。**
4. **每次求解写一个自描述块**，块头形如：
   ```
   ## 采集 2026-09-19 15:33:38 — 10 姿态 / 5 对
   ```
   （时间戳取该次采集的时刻，与 `calib_poses.txt` 的 `# attempt` 行同一个时间来源与格式，
   便于两份文件按时间对上。）
5. **块的内容** = 该次求解控制台输出的**逐字全文**，放在 ```` ```text ```` 围栏里。
6. **块尾追加一节机械臂自报负载**（若该次可用）：
   - `@1168 Load` / `@1176 CenterX/Y/Z`（`appState.forceData.payloadEcho*`，见 `AppState.h`）
   - **`d = cz_robot − c_s`** 与 **`(0, 31.5) mm` 判据的结论**
     （`c_s` 取本次解出的、**沿工具轴的投影**；`d` 的含义与判据的出处见设计规格 §6b）
   - 这三样当天才定下，是这个文档**必须**带上的新内容；缺数据时**照实说"不可用"**，
     不许静默省略、不许给 0。
   - ⚠ 这一节的判据**只是信息**，**不得**参与任何接受/拒绝，也不得改变 `fitRaw` 的判决。
7. **全精度。** 文档里凡是数值，都按**内存里的 double**写足位数 ——
   不要沿用 `%.3f` 那种"够看"的格式。理由见 `main.cpp` 的落盘精度注释：
   力矩重复对的真实差值只有 ~2e-4 N·m，三位小数会把它整个抹掉。**文档是给人读的，但读的人要靠它复算。**
8. **判决之前就要写。** 与 `logPoseData()` 同一个调用点（`main.cpp` 里 `count < 4` 之后的
   `logPoseData();` 附近）—— **被拒绝的那几次同样要留下**，否则"为什么被拒"就只剩滚掉的那几行。
9. **不改任何现有行为**：阈值、模型、判决逻辑、`calib_log.txt` / `calib_poses.txt` 的格式
   **一个字都不许动**。这是一个**只增加输出**的改动。

## 不要做

- 不要动机械臂、不要结束任何正在运行的进程（`Touch_Client.exe` 可能正被操作员用着）。
- 不要构建产物落进 `Touch_Client/tests/`。
- 不要把 `calib_report.md` 加入 git（`calib/` 本就是未跟踪的运行期目录）。

## 验收

- `build.bat` → `Build OK.`
- `tests\build_payload_calibration_test.bat` + `test_payload_calibration.exe` → 仍是 `45 passed, 0 failed`
- **同源可验收**：`'s'` 的屏幕输出与该次在 `calib_report.md` 里的块**逐字一致**。
  （没有实机时，用一个**纯函数**的单测来验：给一段固定的诊断文本，断言写出的块把它完整包住、
  且块头格式正确；再断言追加语义 —— 已有内容一个字节不动。）
- 拒绝的那一次**也**留下块（用单测或读代码说明清楚，别只是声称）。
