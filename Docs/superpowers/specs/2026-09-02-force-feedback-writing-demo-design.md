**日期:** 2026-09-02
**分支:** master
**状态:** 设计定稿（关键决策已确认）

## 1. 背景与目标

Touch-Dobot v3.0 系统的软件实现已基本完成（力反馈、力补偿、奇异避免、姿态控制、坐标标定），现需进行**结项演示**，产出**可留存、可明显感知的成果**。

本设计围绕一个核心演示：**机械臂末端固定一支软笔，操作者用 Touch 设备控制机械臂在纸面上书写**，并通过 **有无力反馈的对照实验**，突出力反馈对控制精度的提升——这正是本项目区别于普通遥控机械臂的核心价值（力觉临场感）。

### 1.1 核心卖点

> 有力反馈时，操作者能"摸到"笔尖与纸面的接触力和笔压，从而控制得更稳；无力反馈时只能靠视觉，笔压失控。两者的差距通过**笔迹粗细均匀度**（定性）和**力传感器笔压稳定性**（定量）直观呈现。

### 1.2 成功标准

1. 机械臂能写出**清晰可辨的"NJU"字母**。
2. **有力反馈组**的笔迹粗细均匀、力曲线平稳；**无力反馈组**笔迹忽粗忽细、力曲线抖动，两组差距肉眼可见。
3. 量化指标（笔压 RMS / 方差、断线次数）可写入结项报告。

## 2. 实验设计

### 2.1 任务

操作者用 Touch 控制机械臂（末端固定软笔），在**软纸 / 软垫**上书写**"NJU"三个字母**（先可用简单图形验证）。

### 2.2 对照条件（唯一变量 = 力反馈开关）

| 组别 | 条件 | 操作者感知 |
|------|------|-----------|
| A 组 | 力反馈开启 | Touch 渲染接触力 + 书写阻力，能"摸到"笔压控制提按 |
| B 组 | 力反馈关闭 | 无触觉，仅靠视觉（看机械臂 / C++ 3D 窗口） |

### 2.3 指标

| 指标 | 类型 | 来源 | 说明 |
|------|------|------|------|
| 笔压稳定性（法向力 RMS / 方差） | 定量·主 | 末端六维力传感器（30004 端口） | 核心量化指标 |
| 断线次数（笔尖离开纸面） | 定量·副 | 力数据阈值判断 | 接触丢失次数 |
| 字迹粗细均匀度 | 定性·副 | 照片 / 扫描 | 有力反馈更均匀 |
| 力曲线对比图 | 可视化 | 落盘数据 | 写进报告 |

### 2.4 关键设计决策（已定）

1. **落地策略为"稳定接触"而非"精确恒压"**：不追求恒定目标力（如 2N），而是"笔尖稳定贴纸、不抬离、不戳破"。原因：纸面高刚度（10~50 N/mm），稳定控压需要 Z 精度 ±0.004~0.02mm，超出 ServoP + 标定的 0.1mm 量级能力。
2. **软垫降刚度**：纸下垫海绵/软垫，接触刚度降至 1~5 N/mm，使笔压对 Z 误差不敏感，控制系统够得着。
3. **软笔可视化力**：软笔（毛笔 / 软头 brush pen）笔压→字迹粗细映射明显、动态范围大，力变化肉眼可见；且笔头柔性进一步吸收 Z 误差。
4. **自由书写而非跟描/重放**：不跟描固定轨迹（跟描精度受视觉手眼协调主导，力反馈贡献被淹没），也不机械臂自动重放（操作者不参与则力反馈无作用）。操作者自由写同一个内容。
5. **落笔/抬笔由 Touch Z 轴自然控制**："NJU"三个字母分离，需抬笔换位。操作者向下移 Touch Z = 落笔（力反馈感知笔尖接触），向上移 = 抬笔，无需按钮联动或自动抬 Z。按钮1 仅作安全触发（按下才传输位置跟随）。

## 3. 硬件准备（夹具）

机械臂末端需固定软笔，胶带无法满足刚性要求，需 3D 打印笔夹。

### 3.1 安装位置（关键约束）

末端力学链路为：**机械臂法兰 → 转接法兰 → 六维力传感器（KWR75B）→ 笔夹 → 笔**。

笔夹必须安装在**力传感器的工具端法兰（下方）**，而非机械臂法兰中心——否则笔尖接触力不经过传感器、无法被测到。

- 力传感器：KWR75B，直径 75mm，应变式六轴力/力矩传感器。
- 传感器上端（法兰侧）：经转接法兰 + 4×M6 + Φ6 定位销，接机械臂末端。
- 传感器下端（工具侧）：**4 个 M6 螺钉孔 + Φ6 销孔的通用接口**，笔夹安装于此。

> 注：笔夹 + 笔的总重量会成为力传感器负载，但 CR 系统（30004）已内部做重力+惯性补偿，不影响笔压净测量。

### 3.2 笔夹方案

- 3D 打印笔夹，OpenSCAD 脚本建模。
- 上端配合面：适配力传感器工具端法兰（4×M6 + Φ6 销通用接口）。
- **夹持为可调内径**：V 型槽 + 侧向螺丝顶紧，适应多种笔杆直径（约 6~14mm），便于实测多种笔后选定。
- **笔杆滑动定位（长度可调）**：夹持段用**短套筒 / V 型槽（约 30~40mm）**，笔杆穿过、笔尖从下方伸出；套筒在笔杆上滑动到合适位置后由侧向螺丝锁紧，保持笔尖位置固定（避免每次换笔重新标定 TCP 偏移）。只要笔杆比夹持段略长即可固定，短笔不受限制。
- 夹持要求：笔垂直纸面、刚性连接不晃动、可更换笔。
- 待定参数：工具端法兰孔位分布圆（建模时从传感器尺寸图 1.2 / 转接法兰提取）。

## 4. 软件改动（设备不可用期间可推进）

### 4.1 力反馈开关（新增，MATLAB 界面控制）

- 开关放在 **MATLAB relay_gui 界面**（按钮/开关控件），**不用键盘快捷键**（防误触）。
- 用于对照实验：A 组开、B 组关。
- 需新增 **MATLAB → C++ 反向命令**（复用 :8888 TCP 连接写回，或新增连接）：MATLAB 控件点击 → 发命令 → C++ 解析 → 切换力反馈状态。
- 关闭时 `HapticCallback` 不调用 `hdSetDoublev(HD_CURRENT_FORCE)`（力归零），位置跟随保持。
- 力反馈状态在 **MATLAB relay_gui 界面**同步显示（`swFF` 开关控件本身即显示 ON/OFF）。
- C++ 3D 窗口保持隐藏、不渲染（自提交 `12b9f43` 起，`display()` 精简为 clear+swap+pollFeedback，`draw3D()` 无调用者）——可视化全部集成在 MATLAB，C++ 侧不重复显示力反馈状态。

### 4.2 力数据落盘记录（新增/扩展）

- 记录时间戳 + 法向力（笔压）+ 全 6 轴力 + 笔尖位姿到文件（CSV/JSON）。
- 供后续误差计算与力曲线绘图。
- 复用现有 `ForcePipeline` 的滤波输出。

### 4.3 笔尖轨迹记录（扩展）

- 记录机械臂笔尖实际轨迹（经 TCP 偏移标定后）。
- 已有轨迹记录基础（HapticCallback 按钮守卫），需扩展为对照实验所需的持续记录。

### 4.4 笔压稳定性计算（新增）

- 计算法向力的 RMS、方差、断线次数。
- 可在 MATLAB 侧（relay 数据）或 C++ 侧实现，产出对比图/表。

### 4.5 笔尖 TCP 偏移标定（实机标定）

- 装笔后，TCP 从法兰中心偏移到笔尖（含传感器高度 + 笔夹 + 笔长），需**实机标定**。
- 方法：标准 TCP 标定（笔尖对准固定点，多姿态记录 GetPose 求解偏移），或与 Touch→Robot 坐标标定协同。
- 标定结果写入配置文件，下次启动加载。

## 5. 演示流程（结项）

1. 启动系统（Touch_Client + MATLAB relay_gui）。
2. 标定（Touch→Robot 坐标 + 笔尖 TCP，若已有标定文件则加载）。
3. **A 组**：开启力反馈 → 操作者写"NJU" → 记录力数据 + 拍照。
4. **B 组**：关闭力反馈 → 操作者写"NJU" → 记录力数据 + 拍照。
5. 展示对比：两张纸并排 + 力曲线对比图 + 量化指标（RMS/方差/断线次数）。

## 6. 风险与应对

| 风险 | 应对 |
|------|------|
| 力反馈贡献被系统噪声淹没，两组差距不明显 | 软垫降刚度 + 稳定接触任务；先实机最小验证（写几笔看差异），再定指标 |
| 笔压控制难度高 | 目标降为"稳定接触"；软笔 + 软纸缓冲 |
| 夹具刚性不足 / 笔晃动 | 一体化 3D 打印件 + 螺丝锁紧 |
| 标定精度不足影响书写 | 优先做 Touch→Robot 标定采集 + 笔尖 TCP 标定 |
| 设备暂不可用 | 先推进软件侧 + 夹具建模，设备回来后直接实机验证 |

---

## 7. 范围外（YAGNI）

- 不追求复杂汉字 / 签名 / 绘画（先保住清晰"NJU"字母）。
- 不实现精确恒压闭环控制。
- 不新增机械臂自动重放功能。
