## A. 两处改动本身的验证（约 3 分钟，不需要写字）

### A1 控制台必须出现"触觉安全提示已关闭"横幅

**预测**：启动后控制台出现一段 `####` 框的横幅（逐条列出失能的四路），**且每 60 秒复报一次**。

**若没有** ⇒ 警告机制本身坏了（那是"代价没兑现"）⇒ 带原始输出回来。

### A2 手感里【不应该】再有排斥

**做法**：按住按钮 1，把笔尖**移向**原来会触发排斥的位置（靠近 `SAFE_Z_MAX=500`，即把笔抬高到 z≈470~490；以及靠近机械臂自身的奇异区）。

**预测**：**全程没有任何"被推开"的力**。只应感到传感器力（≈0，因为笔尖悬空）。

**带回来**：有没有推力感；若有，**在哪个位置、往哪个方向**（那说明关掉的那几路不是元凶，要另找）。

### A3 增益 1:1 的手感

**最客观的做法**：挂**已知质量**（哪怕只是"一个 190g 的东西"这种量级），按住按钮 1 轻托住，
**比较手上托的力与物体重量**（≈1:1 就是对了）。

**预测**：手上托的力**大致等于**物体的重量（1.86 N @190g）。改前只有它的 1/12。

**⚠ 两个已知的副作用，看到不要当成故障**：
- **抖动**：噪声 sd 0.11~0.16 N 会变成手上约 0.15 N 的抖动。**那是传感器底噪，不是 bug。**
  （SNR ≈2~5 是**器件决定的上限** —— 见 run-005 §7.7。）
- 若**闸门**在这时拒绝（`comp − @720` 超 1.2464 N）⇒ `compensated` 全置零 ⇒ **触觉瞬间断一下**。
  那是 **②**（参考量问题），**不是本次改动的回归**。

## B. ★ 端到端书写试一次（首次）

**为什么单独列**：按项目记忆，这条回路的状态是"软件侧完成、待联调" ⇒ **很可能是第一次真跑**。
所以这一节的目的是**发现"哪一段还没接上"**，不是"验收手感"。

**做法**：
1. 笔尖悬空 → 按住按钮 1 → 小范围移动，确认**机械臂跟随**（方向、比例、无卡顿）
2. 在纸上垫软垫（设计文档的决策 2：接触刚度降到 1~5 N/mm）
3. **落到纸面、写几个笔画**（设计文档用 "NJU" 三个字母，要抬笔换位）
4. 观察/感受：
   - 笔尖落下时**手上有没有感到接触**
   - 笔画粗细随压力变化时，**手上的力有没有跟着变**
   - 抬笔/落笔（Touch 的 Z）是否自然

**预测**：能感到接触，且力随笔压变化。**抖动明显**（见 A3）。

**⚠ 已知会挡路的**：书写力若长期 > 1.25 N，**闸门会拒**（②）。⇒ 写轻一点可以绕开，
但这也是"② 早晚要修"的直接体验。

**带回来**：**哪一段没通**（不跟手？笔尖落不到纸？力感觉不对？触觉断？）+ 原始现象描述。
**另外**：若日志里 `force_demo_log.csv` 有数据，留着（它记了 pose + 力 + acc + is_still）。

## C. 可选：漂移率的【长区间】测量（30~60 分钟，不占人）

**为什么**：`τ = 600 s` 是根据 `0.16 N/小时` 定的，而那个数**是从一个数据点推的**。
**⚠ 头 10~20 分钟不能用**：那段时间 `bF` 在吸收"它自己看到的姿态残差"，不是漂移（run-005 §7.5 末）。

**做法**：别碰机械臂，`m` 模式 → `SPACE` 记一次 `bF` → 隔 30~60 分钟再记一次。

**判读（我离线算）**：`ΔbF / 时长` = 真实漂移率 ⇒ 据它复核 `τ` 该不该调。
