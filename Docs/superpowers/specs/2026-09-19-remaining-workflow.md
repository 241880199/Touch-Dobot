### 3.1 开放项 C 的结论（2026-09-21 落地）

**判决（只读诊断，未改代码、未跑客户端、未动机械臂）:**
全程取证与方法见 `Docs/superpowers/evidence/2026-09-21-z-gap-report.md`。

1. **「38~64 N」不是 z 上的任何实测差。** 它是 `.superpowers/sdd/runtime-guard-report.md` §3.1.1
   那句 `tol_M / |c_s_横向|`：**力矩通道**要把一个 ΔFz 顶到 `tol_M = 0.03 N·m` 之上，
   那个 ΔFz 得有多大。四个数 `38.4 / 60.1 / 53.0 / 63.7 N` 我按四份夹具**逐位复现**
   （`|c_s_横向| = 0.781 / 0.499 / 0.566 / 0.471 mm`）。**它是探测下限，不是缺陷尺寸。**
2. **它作为"尺寸"也已经失效:** 力矩三个分量自 2026-09-21 起不投票（`g_guardVote`）
   ⇒ 那句话描述的门**不存在**。同一件事已写在 `Config.h` 的 `FORCE_GUARD_TOL_FORCE_N`
   注释块与 `ForceCompensation.cpp` 的 `g_guardVote` 注释块里。
3. **它也当不成 `A` 第三行的误差尺寸:** `A` 的第三行整行只值 `0.410561 kg × 9.81 = 4.028 N`
   ⇒ 38~64 N 是它的 **9.5 ~ 15.8 倍**。要那么多力，这一行得是实测值的 9~16 倍。
4. **实测把"第三行估错"排到 240~400 倍以下:** 在库里唯一的三轮 `@720` 数据上拟合
   `comp − @720 = c + K·g`（`K = A_臂 − A`），其**第三行**模是
   **0.0078 / 0.0042 / 0.0164 kg = 0.076 / 0.041 / 0.160 N**（噪声由同姿态复采给）。
   十三次拟合（`calib_report.md` 九节 + 四份夹具）里，除 `2026-09-20 20:27:36` 那一次，
   第三行的模全部落在 `0.410561 ~ 0.418826 kg`（`m = 0.4159 kg`），与另两行近正交。
5. **原来那条"秩 2"依据属于 `@576`，不属于 `A`:** 那串奇异值 `[0.212 0.201 0.008]` 的对象是
   `@576` 的**重力方向响应矩阵**（我在 `12:38` 夹具上逐位复现）。我们的 `A` 是在 **`@1304`**
   上解的，而 `@1304` 没被任何负载模型减过 ⇒ 它的第三行必须是满的，实测也是满的。

**⚠ 关闭它**不**等于**下面三件事，明写在这里以免被读成"z 都好了":

| 仍然没有 | 是什么 |
|---|---|
| **z 方向没有守门** | `Fz` 不投票，力矩也不投票 ⇒ 一个**中等大小**的第三行误差（例如把第三行缩一半 ⇒ 约 2 N 的姿态相关 z 误差）**没有任何通道会拒**。本项只说"没看到这种错，且 38~64 N 这个尺寸不是它的尺寸" |
| **第三行的绝对精度** | 仓库里**没有** z 方向的力真值。能量到的是**与机械臂那套模型的差**（≤ 0.160 N），而机械臂那套模型不是独立真值 ⇒ **两者同错看不出来**。另一个界是本地失拟 `eps_甲 ≤ 0.287 N`（夹具口径） |
| **`Fz` 不投票的理由现在是否还成立** | **按原样不复现**（**定案范围 = 第 2、3 轮与三轮合计**）。复测 `@720`：`K` 的"第三行比另两行小 8~15 倍"这个形状**没有**（三轮 `0.179× / 2.092× / 0.721×`，其中一轮第三行最大；z 行模 `0.0051 / 0.0157 / 0.0164 kg`，逐分量 `se 0.0010 ~ 0.0027 kg` ⇒ **第 1 轮的 `0.179×` 在约 2σ 以内、单独不定案**）。`@720` 的 `K` 确实小了一个量级，但**小的是分母**：**x/y 两行**从 `0.20 ~ 0.21 kg` 塌到 `0.0075 ~ 0.0286 kg`，而 **z 行几乎没动**（`0.0148 ~ 0.0201 kg` → `0.0051 ~ 0.0164 kg`）⇒ 这不是"z 行被修好了"。差别最清楚的地方是**差量**：`comp − @576` 的 `K` 第三行被抑制 14~39 倍，`comp − @720` 的**没有被抑制**。⇒ 代码里那两行"未复测 / 不许读成已验"**仍然是对的**，而本次复测的结论是"它按原样不复现"。**⚠ 改不改掩码是另一个决策**（要消费一个"接触下未验证"的参考量，见开放项 A 与前置复核 §4.2①），**不在本项内，本次也未改任何代码。** |

## 5. 硬约束（每一步都适用）

**安全（用户原话）**
- **"1.5 kg太重了，昨天已经测试过了，会导致机械臂迅速运动报错"**
- **"直接修改参数让机械臂动太危险了，有没有别的方案"**
- **"门限可以适当降低标准，但安全起见不符合时还是要拒绝"**
- **"在运行过程中机械臂需要得到正确的负载参数才能正确执行指令"**
- **不要杀运行中的 `Touch_Client.exe`**

**工程纪律（今天用代价换来的）**
- **"任何猜测以及偏差（如 ψ）都不可取"** —— 参数一律实机测得 / 由数据算出
- **一条路若自带判据，先用那条路的判据**（"补偿后应姿态无关"、"`@1304` 与 `@576` 应一致"）
- **写规格/注释前，每个前提、出处、数字回到源头核一遍**；核不出来就别写，改说它出自哪里
- **不许动**：门限公式 / 求解器 / 模型形式 / **`A` 用 `A_F`** / 两份日志的列格式 / `#if 0` 块 / 证据文件
- **`Touch_Client.exe` 在跑时构建会 `LNK1168`** —— 报告并停下，不要 `taskkill`
- **命令里不要出现反斜杠**（会被折叠成真控制字节）
