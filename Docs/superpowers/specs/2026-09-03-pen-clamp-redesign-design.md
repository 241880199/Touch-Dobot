# 笔夹重设计 — 轴向顶紧 + 可调自定心夹持（设计文档）

> 日期：2026-09-03
> 范围：重设计 `Hardware/pen_clamp`，满足①适配常见毛笔的笔径与笔长范围②夹持点落在手握位③笔尾端轴向顶紧力传感器以直传书写力。

## 1. 背景与问题

现款 `Hardware/pen_clamp.scad` 是「V 型槽 + M5 顶紧螺丝」的短套筒结构（夹持段 35mm）。它在下面两点上不满足结项演示需求：

1. **笔长无法适配**：只能靠笔杆在 35mm 套筒里滑动定位，笔尖伸出量、笔尾是否到位都不受控，且无法覆盖毛笔 170~300mm 的长度跨度。
2. **夹取位置与力传递不对**：夹持点落在笔杆中部（不是手握位），书写力靠侧向摩擦传入传感器——摩擦有损耗、笔杆可能滑移，测到的笔压不真实。

本设计把夹持逻辑反转：**书写力沿笔轴直传传感器，笔夹退化为「扶正 + 导向 + 防落」**。

## 2. 需求（已与用户确认）

| 项 | 值 | 说明 |
|---|---|---|
| 力传递方式 | 轴向直接顶紧 | 笔尾端（笔顶）顶住传感器 Φ31.5 凸台面，力沿笔轴直传；笔夹不承书写力 |
| 笔杆直径 | 6~16mm | 覆盖常见毛笔杆 7~15mm + 两端余量，需自定心（否则笔轴偏心→寄生侧向力/力矩）|
| 笔总长 | 170~300mm | 小楷 ~180 到大楷 ~300 |
| 夹持点 | 可调 | 沿笔杆滑动锁定，落在手握位（离笔尖 50~120mm 量级，毛笔五指执笔，随笔长/握法变）|
| 传感器接口 | 4×M6 @Φ50、2×Φ6 销 @R25/45°、Φ31.5 凸台高 7mm | 凸台高度 = 31.5（总高）− 24.5（法兰安装高）|

## 3. 设计决策

**选定方案 A：可滑导向 + 分档可换自定心夹头。**

- 否决「方案 B（对向 V 型自定心钳 + 反向螺纹丝杠）」：反向丝杠打印/采购麻烦，精度依赖打印。
- 否决「方案 C（固定孔径套筒）」：档位粗、偏心随档位跳，且换笔要拆装。

**关键推论（决定结构尺寸）：** 笔尾顶传感器、笔尖朝纸面，故夹持点（离笔尖 50~120mm）实际位于传感器下方约 **100~210mm** 处（随笔长/握法变）。导向结构必须是一段 ~250mm 的竖向可滑导轨，而非现款的 35mm 短套筒。

## 4. 结构设计

### 4.1 竖向堆叠（从上到下）

```
机械臂法兰
  └─ 力传感器 KWR75B（Φ66 端接臂，Φ31.5 凸台端朝下，凸台高 7mm）
       └─ 笔夹顶部法兰（Φ68 × 6mm）
            ├─ 4×Φ6.5 M6 过孔 @Φ50 + 2×Φ6 销孔 @R25/45° + 中央 Φ32 凸台过孔
            ├─ 两根导向柱（Φ8 光轴 × ~250mm，装在法兰两侧耳座上）
            │     └─ 底部横梁（把两柱下端连成门架，增刚度）
            └─ 滑动导向块（沿两柱上下滑，锁高螺丝固定）
                  └─ 分档自定心夹头（三瓣开口锥套 + 锥面锁紧螺母）
笔：从下方穿入夹头 → 向上滑 → 笔顶顶住 Φ31.5 凸台面 → 笔尖朝纸面
```

### 4.2 力传递路径

```
纸面 → 笔尖 → 笔杆（轴向） → 笔顶 → 传感器 Φ31.5 凸台面 → 传感器
```

夹头只做两件事：①扶正笔杆使其与传感器共轴（避免寄生侧向力/力矩）②轻夹住笔防下滑（只需克服笔重 ~0.3N，远小于书写力 1~5N）。**书写力不经过夹头。**

### 4.3 凸台高度与法兰厚的关系

凸台高 7mm、笔夹法兰厚取 **6mm**：凸台会凸出法兰下表面 1mm，笔尾端从下方能干净地顶到凸台面，无需往孔里够。这是把 `FLANGE_T` 从现款 8mm 改为 6mm 的原因。

## 5. 零件清单与关键尺寸

| 零件 | 数量 | 关键尺寸 | 备注 |
|---|---|---|---|
| 顶部法兰 | 1 | Φ68 × 6mm；4×Φ6.5 过孔 @Φ50、2×Φ6 销孔 @R25/45°、中央 Φ32 凸台过孔 | 复用现款孔位，追加 2 个导向柱耳座 |
| 导向柱 | 2 | Φ8 × ~250mm | **建议用市售 Φ8 钢光轴**（比打印柱刚硬、便宜、标准件），打印耳座固定 |
| 底部横梁 | 1 | 连接两柱下端 | 门架刚度，可选 |
| 滑动导向块 | 1 | 两柱过孔（Φ8 滑配）+ 中央夹头座 + 锁高螺丝（柱上开口夹紧）| 沿柱滑动，覆盖 ~100~210mm 全行程（柱长 250mm 留余量）|
| 分档夹头 | 3 | 内径档 **6-10 / 10-13 / 13-16mm**（三瓣开口锥套）| 自定心，换笔换档 |
| 锁紧螺母 | 1 | 与夹头锥面配（打印粗牙）| 旋紧夹紧笔，轻夹即可 |

**夹头自定心原理：** 三瓣开口锥套（split collet）被锥面螺母一压，三瓣向内均匀收缩，任意直径圆都被夹在同一轴线上 → 笔轴恒等于传感器轴，6~16mm 全程无偏心。

**导向柱耳座位置约束：** 需避开中央凸台孔（R16）、4×M6（R25）与 2×Φ6 销孔（R25），落在法兰 R28~R32 范围内，两柱成对径布置（建议 30°/210°）。耳座可做成法兰上外伸的小耳，具体位置在 OpenSCAD 建模时核定。

## 6. 装配与换笔流程

**装配：**
1. 顶部法兰 4×M6 + 2×Φ6 销固定到传感器工具端。
2. 插入两导向柱 → 装滑动块 + 底部横梁。
3. 按笔径选夹头档 → 装入滑动块。

**装笔（关键流程）：**
1. 笔从下方穿入夹头。
2. 向上推笔，**直到笔顶顶住传感器 Φ31.5 凸台面**（感到到位）。
3. 下滑动块，使夹头落在**手握位** → 锁高螺丝固定。
4. 轻旋锁紧螺母夹住笔（只扶正 + 防落，勿死拧）。

**换笔：** 松螺母 → 抽旧笔 → 换档（如需）→ 插新笔顶到位 → 锁高 → 轻夹。每次装笔都「顶到位」，笔尖相对传感器的高度随笔长变，**TCP 偏移需重标**（复用既有 `TcpCalibration` 流程）。

## 8. 风险与应对

| 风险 | 应对 |
|---|---|
| 250mm 悬臂刚度不足 | 两柱对称 + 底部横梁门架；导向柱用 Φ8 钢光轴 |
| 打印夹头锥套精度不够 | 夹头内径留 +0.3~0.5mm 余量，靠三瓣收缩适配；必要时砂纸修 |
| 笔顶非平面（圆头/挂绳孔）顶不住 | 凸台面与笔顶间加一片 Φ8~16 平垫片 |
| 抬笔瞬间笔脱离传感器 | 夹头轻夹已足够（笔重 << 书写力）；若仍晃，传感器侧加轻弹簧顶柱 |
| 长柱与纸面/工作台干涉 | 装夹前确认纸面到传感器下沿的净空 ≥ 300mm + 余量 |

## 9. 非目标（YAGNI）

- 不做全程免换件的单一夹持机构（反向丝杠等）。
- 不做自动顶紧/自动换笔。
- 夹头用 3D 打印件（不做金属夹头）；导向柱建议市售 Φ8 钢光轴（标准件，非打印）。
