## C 段 —— §5 `@720` 的符号约定 ★ 唯一无法离线替代的一项

**为什么只能上机：** 全库没有 `@720` 的符号约定（与 `@1304` 反相关，文档无说明）。
静止时 `comp ≈ 0` 且 `@720 ≈ 0` ⇒ "两者一致"是**零信息量**。

**★ 三条约束（都由代码定死，漏掉一条实验就是零信息量）：**

1. **力必须加在【水平】方向（X 或 Y）。**
   投票掩码是 `g_guardVote[6] = {true, true, false, false, false, false}`（`ForceCompensation.cpp:178`）
   ⇒ **只有 `Fx` / `Fy` 投票**（`Fz` 不投票、力矩三路不投票）。
   **⇒ 吊砝码（竖直 −Z）不会让闸门拒绝，验不了符号。**

2. **力要 > 0.62 N。** 容差 `FORCE_GUARD_TOL_FORCE_N = 1.2464 N`（`Config.h:269`）。
   若符号相反，`comp − @720 ≈ 2F` ⇒ 需要 `2F > 1.2464`，即 **`F > 0.6232 N`**。
   **小于它的话，反号也会放行 ⇒ 零信息量。建议推/拉约 1.5 N。**

3. **施加后【尽快】读（2 秒内）。** 两个时钟会吃掉信号：
   - 闸门 EMA `FORCE_GUARD_EMA_ALPHA = 0.02`（`Config.h:273`）⇒ 约 **1.7 s** 才收敛；
   - **★ 静止时在线零偏 EMA** `FORCE_BIAS_EMA_ALPHA = 0.01`（`Config.h:131`，仅 `isStill()` 时跑，
     `ForceCompensation.cpp:1032`）⇒ 约 **3.3 s**，会**把静态外力吸收进零偏**
     ⇒ 补偿值自己慢慢回到 0。

**做法：**

1. 先按 A 段确认闸门**放行**（这是基准）。
2. 进 `'m'` 模式（`m`），**不要按 `d`** —— 保持刚性锁定。
3. 按 `SPACE` 记**基准**（SPACE #1），抄下 `@720 F=(...)` 这一行。
4. **沿 +X（或 +Y）施加约 1.5 N，保持不动。**
5. **在 2 秒内盯闸门那一行**：
   - 仍**放行** ⇒ 初步读作**同号**；
   - **拒绝** ⇒ **把那一整张逐通道表抄下来**（它印的是 `comp − @720` 的逐通道值与符号）。
6. 仍保持施力，按 `SPACE` 记一笔（SPACE #2），抄下 `@720 F=(...)`。
   **★ 必须看到 `@720` 动了 —— 没动说明力没加到，本次实验作废。**
7. 松手。

**★ 判读【带回来离线做】，别在现场下结论**，因为"拒绝"有两种成因，得用数据分开：

| 成因 | 特征 |
|---|---|
| **真反号** | 拒绝**很快**（~2 s 内）出现，`comp − @720` 量级 ≈ **2F** |
| **同号 + 零偏 EMA 吸收** | 拒绝**滞后**（>3 s）出现，`comp − @720` 量级 ≈ **1F**，且符号与推的方向**相反** |

（后者是机制性的、不是故障 —— 它就是上面第 3 条那个 EMA 在起作用。）

**★★ 若确认是反号：立刻停下报告。** 那不是调参问题 —— 真实外力下闸门会看到约 **2×** 偏差。

**带回来的东西：** 施加方向与量级 · 两次 `@720` 读数 · 闸门放行/拒绝 · 拒绝时那张表 · 或明确写"未做"。

> **★ 这里不需要 `a_matrix`（2026-09-21 更正）。** 本文档早先写的是"用已装的 `a_matrix`
> 反算 `Δcomp`"——**那是错的**：`a_matrix` 作用在**重力向量** `g` 上（模型是 `F = b_F + A·g`），

> （这也是 §5 的判据：把 `Δ@720` 与 `Δ@1304` 逐分量比符号。）
