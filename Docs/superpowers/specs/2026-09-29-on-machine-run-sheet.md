## 1. 实验 A（主）—— 判 `act` 的性质

**原理**：物理上不可能"一帧内跳 4.5 mm"（= 550 mm/s 瞬时）。所以
**只看 `act` 跟不跟得上 `tgt` 的台阶**。

### 步骤（做 3 遍）

1. 臂停在某个方便的位置，**按住按钮1**（力反馈开着、`sendPosition` 在跑）。
2. **静止 3 秒** —— 给分析留一段基线。
3. **一次性、单向、快速**把 Touch 手柄推/拉一大段（**≥20 mm，不要来回搓**），然后**停住**。
4. **再静止 2 秒**，别松按钮1。
5. 按 `'n'`。
6. 重复 3 次（**都朝同一个方向**，这样三次可直接平均）。

### 读法（离线，看 `force_wave.csv` 最新那块的第 2/3 组）

| `act` 的表现 | 结论 | 下一步 |
|---|---|---|
| **1~2 帧内**跳到与 `tgt` 同幅度 | **回显** | 那 200 ms 只是通信+队列；**得先解决"机械臂真实运动怎么测"**，其余免谈 |
| 用**若干帧斜坡**爬过去，带**过冲或稳态误差** | **真反馈** | 106~203 ms 是**环路里的真延迟** ⇒ 查它从哪来（`ServoP` 队列？30004 缓冲？） |

> **先验（来自离线数据，别忘）**：`act` 在 09-24 那块里**完全没有复现 `tgt` 的 ±4.5 mm 阶梯**
> —— 这已经偏向"真反馈"。实验 A 要钉的是**那 200 ms 本身是不是真的**。

## 2. 实验 B —— 力反馈 **开 / 关** 的对照（`ff` 列就是为它加的）

**目的**：09-24 用"关掉力反馈就不抖"钉死了闭环，但那次是**现场判断**、不是受控比较
（报告自己写着"每次动作都不一样 ⇒ 数据不能替归因背书"）。这次用同一套动作做干净 A/B。

### 步骤

1. **力反馈开着** → 做实验 A 那套动作 3 遍 → 按 `'n'`。
2. **关掉力反馈**（MATLAB 侧那个 `swFF` 开关）→ **做一模一样的一套动作** 3 遍 → 按 `'n'`。
3. 两段都记下**起始时刻**，方便事后按 `ff` 列切。

### 读法

- 对比两段里 `dev` 的幅度/谱峰 ⇒ **环路对"手柄被推着动"的贡献有多大**（这一条是定量，不是"感觉"）。
- `ff` 列会逐帧标明开关状态 ⇒ **不需要靠回忆分段**。

## 3. 实验 C —— 一段**确证的空载**

**目的**：把那个 **~2 Hz 峰**分成"载荷下的粘滑"与"环路/机械"。
离线数据答不了，因为 09-24 那批 `|raw_z|` 全在 2.36~4.93（工具自重与按压同量级），**没有空载段**。

### 步骤

1. **把笔抬离桌面**（不接触任何东西），**力反馈开着**，按住按钮1。
2. 静止 3 s → 按 `'n'`。
3. 再把笔**轻轻压住**桌面（约平时写字的压力），静止 3 s → 按 `'n'`。

### 读法

- 空载段 `raw_x` 在 1~4 Hz **还有峰** ⇒ 不是载荷（是环路或机械振动）；
- 空载段**没峰**、按压段才有 ⇒ 是**载荷下的粘滑** ⇒ 与"写字阻力"同源，与 09-24 的结论一致。
- ⚠ 判"空载"用 **`filt ≈ 0`**（09-24 报告里定的判据），不要用 `raw_z` —— 它含工具自重。
