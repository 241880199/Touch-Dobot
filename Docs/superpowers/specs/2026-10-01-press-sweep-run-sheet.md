## 1. ★ 两趟，**同一批位姿**，一悬空一压着

```
A 趟（悬空基准）: 手离开桌面（笔尖不碰任何东西）
   → 按 'w' 开始 → 按住按钮1 → 按 'r' → 撑完 300 秒 → 按 'w' 停
   → 复制改名：force_wave_cont_air.csv

B 趟（压着写）:  笔尖【轻压】桌面（约平时写字的压力，看 filt_z 到 −1 N 量级）
   → 按 'w' 开始 → 按住按钮1 → 按 'r' → 撑完 300 秒 → 按 'w' 停
   → 复制改名：force_wave_cont_press.csv
```

★ **两趟要在【同一个位姿】上做**（先做 A 再原地做 B，中间不要按键2 换位姿）——
否则"接触"与"位姿"两个变量会缠在一起。

⚠ **A 趟是必须的**：没有它就没有同一批位姿下的对照（现有那两轮的位姿都不同）。

## 2. 判据（**先写死**）

离线算 **`filt_x` / `filt_y` 的谐波结构**（与 §17/§18 同一个算法），比两趟：

| 看到什么 | 结论 |
|---|---|
| **两趟的谐波结构【基本一样】**（基频占比、主导谐波次数相近） | ⇒ **接触不改变机制** ⇒ 悬空扫出来的那条结论可以直接推广到写字 |
| **两趟【明显不同】**（例如接触时基频占比大幅上升/下降，或主导谐波换次） | ⇒ **接触引入了新机制**（很可能是摩擦/粘滑）⇒ **那时要单独查接触那一支** |

**参考值**（悬空、旧位姿、±5mm）：`filt_x` 基频 **5.0 ~ 14.0%**，主导谐波在 2×/3×/4× 之间跳。
⚠ **换位姿会改这个数**（§18）⇒ **只能和同一批位姿的 A 趟比**，不能和旧轮次比。
