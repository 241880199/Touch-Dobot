# 笔夹硬件改进 — 去热熔 + 修锥面（设计文档）

> 日期：2026-09-07
> 分支：`feat/pen-clamp-redesign`
> 前置设计：[2026-09-03-pen-clamp-redesign-design.md](./2026-09-03-pen-clamp-redesign-design.md)（轴向顶紧 + 可滑自定心夹头，已实现于 08a0191）
> 范围：对已实现方案做两处改进——①去掉热熔嵌件，改用六角螺母嵌槽；②修复锁紧环与三瓣的锥面线接触为全锥面贴合。**不改动整体架构（法兰 / 块 / 横梁 / 三档夹头 / 锁紧环五件）与力传递路径。**

## 1. 背景与问题

现状（08a0191）已满足核心需求，但存在两处不理想：

1. **热熔嵌件（3 处 M4）**：块底 2×M4（锁紧环上拉吃丝）+ 块侧 1×M4（锁高吃丝）均用 M4 热熔嵌件，外径 Φ4.5 是非标规格（市售多为 Φ5.5~6mm）、难采购，且需热熔枪（烙铁+嵌件头）、有压歪/熔穿/温度不够脱出的风险。
2. **锁紧环锥面线接触**：`3b50cd2` 把夹头三瓣锥反转为「自由端窄 Φ22 / 基端宽 Φ25」，但锁紧环内锥仍是旧向「下宽 Φ25.5 / 上窄 Φ22.5」，两锥反向 → 只在环上沿一条线接触（README「已知限制」）。夹紧力集中一条线，钢环上沿会啃 3D 打印的塑料三瓣。

## 2. 设计决策（已与用户确认）

| 决策 | 结论 |
|---|---|
| 改进范围 | 去热熔 + 修锥面（**不做**「更彻底重设计」，如分体夹块/卡扣） |
| 热熔替代方式 | 六角螺母嵌槽（标准 M4 六角螺母 GB/T 6170，对边 7mm / 厚 3.2mm） |
| 嵌槽配合 | 轻微过盈（槽对边 **7.0mm**，与螺母等值；3D 打印孔会略缩 → 呈压入卡住） |
| 6mm 细笔 | 本设计**不额外保证**稳稳夹 6mm 细笔（现状也是贴边值，见 §7） |

## 3. 改动 ①：去热熔 → 六角螺母嵌槽

### 3.1 新增 `hex_nut_pocket()` 模块

卡入标准 M4 六角螺母（GB/T 6170：对边 `s=7.0mm`、厚 `m=3.2mm`）：

- 槽对边 `M4_NUT_AF = 7.0`（与螺母等值，靠打印缩水呈轻微过盈 → 按入卡住）
- 槽深 `M4_NUT_H = 3.5`（螺母 3.2 + 0.3 让位，螺母略沉入面内不凸出）
- 槽为六角棱柱（OpenSCAD `circle(r=AF/√3, $fn=6)` 拉伸），开口朝螺母进入方向

### 3.2 三处替换

| 位置 | 现状 | 改后 |
|---|---|---|
| 块底 2×M4（锁紧环上拉） | 盲孔 Φ4.5 深 12mm，吃丝 | 孔改**通孔 Φ4.5 贯穿块高**；块底面（z=−20）开六角槽开口向下，螺母压入卡住 |
| 块侧 1×M4（锁高顶丝） | 水平 Φ4.5 孔吃丝（沿 +X 从侧面钻入，Y=12.63） | 保留水平孔；+X 面开六角槽，螺母压入卡住 |

### 3.3 装配与紧固件

- 块底 2 孔：M4 螺栓自下穿过锁紧环耳 → 拧入块底螺母。螺栓 **M4×16**（环 6 + 螺母 3.2 ≈ 9.2mm 吃深，M4×12~20 皆可）。
- 块侧 1 孔：M4 顶丝（内六角平端）拧入螺母，尖端顶光轴锁高。顶丝 **M4×10**（沿用，不做改动）。
- 螺母方向：块底槽开口朝下，靠过盈卡住不掉；若打印后太紧可用锉刀微扩，太松在槽内点一滴胶（装配兜底）。

## 4. 改动 ②：修锥面（锁紧环内锥反转 + 缩短）

### 4.1 原理

三瓣手指：外径 `Φ22`（自由端，下）→ `Φ25`（基端，上），高 16mm，锥度 `3/16`。
锁紧环：套在手指上、自下上移夹紧。要实现**全锥面贴合**，环内锥必须与手指外锥**平行**（同向、同锥度 `3/16`），即环内锥「下窄上宽」。

- 环内锥与手指外锥平行后，夹紧量 = 锥度 × 轴向行程 = `3/16 × (16 − RING_L)`。
- 环 12mm → 行程 4mm → 夹紧 ~0.75mm（太弱，细笔夹不住）。
- 环 6mm → 行程 10mm → 夹紧 ~1.7mm（够用，全锥面均匀夹紧）。

故 **`RING_L` 12→6mm** 是「全锥面贴合 + 保夹紧量」的必然结果。6mm 环对轻夹（只扶正+防落）刚度足够。

### 4.2 参数变更

| 参数 | 现值 | 新值 | 说明 |
|---|---|---|---|
| `RING_L` | 12 | **6** | 环高（轴向厚度），换取夹紧行程 |
| `RING_ID_BOT` | 25.5 | **`COLLET_FINGER_BOT + 0.2` = 22.2** | 环下端口径，套过自由端 Φ22 留 0.2 余量 |
| `RING_ID_TOP` | 22.5 | **`RING_ID_BOT + (COLLET_FINGER_TOP−COLLET_FINGER_BOT)·RING_L/COLLET_FINGER_L` = 23.3** | 环上端口径，与三瓣锥平行 |

（`RING_ID_TOP` 用派生公式而非写死，锥度与三瓣单源一致，日后改手指锥度环自动跟随。）

### 4.3 效果

- 全行程均匀夹紧 **~1.7mm**（环下沿 23.875−22.2 = 环上沿 25−23.3 ≈ 1.675mm，处处一致）。
- 接触从「一条线」变「整段 6mm 锥面」，塑料三瓣不再被钢环上沿集中啃压。
- 笔径覆盖基本持平：S 档最细 ~6.3mm（原 ~6.1mm，见 §7）。

## 5. 参数汇总（新增/变更）

```openscad
// —— 六角螺母嵌槽（新增）——
M4_NUT_AF = 7.0;   // 对边，与 M4 螺母 s=7 等值（打印缩水→过盈卡住）
M4_NUT_H  = 3.5;   // 深，螺母 m=3.2 + 0.3

// —— 锁紧环（变更）——
RING_L       = 6;                                              // 原 12
RING_ID_BOT  = COLLET_FINGER_BOT + 0.2;                        // 原 25.5 → 22.2
RING_ID_TOP  = RING_ID_BOT + (COLLET_FINGER_TOP - COLLET_FINGER_BOT) * RING_L / COLLET_FINGER_L;  // 原 22.5 → 23.3
// clamp_ring 内锥: cylinder(d1=RING_ID_BOT, d2=RING_ID_TOP, h=RING_L)   // 下窄上宽（与原相反）
```

## 7. 验证计划

1. **OpenSCAD 重导**：`PART=3`（block）、`PART=8`（ring）导出 STL，做 bbox/顶点复核（block 顶/底六角槽位置、ring 内锥 d1<d2 方向）。
2. **装配逻辑复核**：ring 内锥下窄上宽能套过三瓣自由端 Φ22；六角槽不干涉夹头座/光轴套筒。
3. **打印前卡尺复核**：凸台高度 7mm、M6 孔深（沿用 README 既有待测项）。
4. **打印手感验证**：螺母压入是否卡住不掉；锁紧环 6mm 全锥面夹紧是否均匀、手感是否够扶正+防落。

## 8. 非目标（本次不做）

- 不保证稳稳夹 6mm 细笔（若需，属「更彻底重设计」：缩 S 档孔径或加档，需重导三档夹头）。
- 不做分体夹块、卡扣、反向丝杠等锁光轴/锁紧替代机构。
- 不改力传递路径、传感器接口（M6@Φ50 / 销 @R25/45° / 凸台 Φ31.5）与三档夹头孔径。
