# 具身智能体机械臂-Touch 远程交互系统研发

## 📖 项目简介
本项目旨在研发一套“人机分离”的远程交互系统。操作者通过 Force Dimension Touch 设备远程控制机械臂，并实时获取机械臂末端的力觉反馈，实现双向力反馈闭环。
**核心技术栈：** C++ / OpenHaptics / MATLAB / TCP Socket

## 一、 四个角色的核心职责与交付物

### 1. 王梦瑶：Touch 端核心开发
* **职责定位**：负责由人操作的 Touch 设备（手柄）的控制与反馈，并通过 TCP 与中继站通信。
* **核心工作**：
    * **数据读取**：利用 C++ 和 OpenHaptics SDK 读取手柄的实时空间坐标 $(x, y, z)$ 及按钮状态。
    * **通信交互**：作为 TCP 客户端连接中继站，发送原始 Touch 坐标数据（格式按协议约定），接收机械臂反馈的力数据。
    * **力反馈渲染**：根据收到的力数据，调用 HDAPI 驱动手柄产生反向阻力（触觉渲染）。
    * **可视化**：使用 OpenGL/GLUT 开发可视化界面（如显示手柄位置、力矢量箭头）。
    * **心跳响应**：收到中继站发来的 `PING|xxx` 消息时，应回复 `PONG|xxx` 用于网络时延测量。
* **交付物**：Touch 控制程序（含 TCP 通信、力反馈、可视化）。

### 2. 王安安：中继站与机械臂控制
* **职责定位**：负责数据中转、坐标转换、机械臂直接控制，以及力反馈数据的采集与回传。
* **核心工作**：
    * **中继站服务**：在 MATLAB 中启动 TCP 服务器，监听 Touch 客户端的连接。
    * **坐标转换与指令生成**：接收 Touch 端发来的原始坐标，调用坐标转换算法，生成机械臂可执行的运动指令（如 `MoveJ` 或点位数据）。
    * **指令转发**：将生成的指令通过 TCP 客户端转发至机械臂对应的控制端口（如 30003 运动端口、29999 使能端口）。
    * **机械臂控制**：封装机械臂 SDK，实现运动控制、状态查询等基础功能。
    * **力反馈采集**：实时读取机械臂末端的力/力矩传感器数据（或通过电流估算）。
    * **数据回传**：将采集到的力数据通过 TCP 发送给 Touch 端。
    * **时延监控**：定时发送 PING 探测包，计算并显示网络单向时延与中继转发时延。
    * **日志与绘图**：记录所有通信日志，实时绘制时延曲线。
* **交付物**：MATLAB 中继站完整工程（含机械臂控制模块、坐标转换模块、TCP 通信模块、GUI 界面）。

### 3. 陈佳琪：通信协议与系统集成
* **职责定位**：定义 Touch 与中继站之间的通信规范，协助两端进行数据联调。
* **核心工作**：
    * **协议设计**：制定基于 TCP 的文本消息格式（如 Touch 坐标数据格式、机械臂指令格式），确保指令清晰、易解析。
    * **数据包规范**：定义力反馈数据的封装格式（如直接透传机械臂原始数据，或约定 JSON 结构）。
    * **时延测量协议**：约定 PING/PONG 消息格式（`PING|序列号` → `PONG|序列号`），用于计算网络时延。
    * **联调支持**：协助 Touch 端与中继站进行网络连通性测试，解决数据收发不一致问题。
* **交付物**：《通信协议规范文档》及示例代码片段。

### 4. 张苏楠：算法与数据处理 (系统大脑)
* **职责定位**：解决“抖动”、“坐标不一致”及“安全边界”问题。
* **核心工作**：
    * **坐标变换**：推导并验证 Touch 坐标系到机械臂坐标系的转换矩阵，供中继站调用。
    * **滤波算法**：设计滤波器（如卡尔曼滤波、滑动平均），处理机械臂回传的力数据噪声。
    * **力映射模型**：建立“机械臂末端受力 → Touch 输出力”的映射关系，确保力反馈真实自然。
    * **安全机制**：计算虚拟墙与安全边界，在指令生成前进行限位检查，防止机械臂碰撞。
* **交付物**：核心算法函数库（如 `transform_coordinate()`, `filter_force()`, `check_safety_boundary()`）。

## 二、 系统架构与数据流转

本系统由两台计算机组成：
- **PC-A (Touch 端)**：运行 Touch 控制程序，作为 TCP 客户端。
- **PC-B (中继站端)**：运行 MATLAB 中继站，作为 TCP 服务器（对 Touch）和 TCP 客户端（对机械臂），并直连机械臂控制器。

### 1. 正向链路（人 → 机械臂）：运动控制
1. **【王梦瑶】** 读取 Touch 原始坐标 $(x, y, z)$ 及姿态，按协议格式打包，通过 TCP 发送给中继站。
2. **【王安安】** 中继站接收 Touch 坐标，调用坐标转换算法，将 Touch 位姿映射为机械臂目标位姿。
3. **【王安安】** 根据转换后的位姿生成机械臂运动指令（如 `MoveJ(x,y,z,rx,ry,rz)`）。
4. **【王安安】** 将指令通过 TCP 或 SDK 发送给机械臂控制器。
5. **【王安安】** 机械臂执行运动。

### 2. 反向链路（机械臂 → 人）：力反馈触觉
1. **【王安安】** 通过机械臂 SDK 实时读取末端力/力矩数据。
2. **【张苏楠】** 提供的滤波算法对原始力数据进行平滑处理（在中继站内调用）。
3. **【王安安】** 将处理后的力数据通过 TCP 连接发送给 Touch 端。
4. **【王梦瑶】** Touch 程序接收力数据，调用 OpenHaptics SDK 驱动手柄产生相应的阻力。
5. **【王梦瑶】** 操作者感受到力反馈，完成闭环。

## 三、 项目推进阶段与先后顺序

### 第一阶段：环境搭建与单点验证
**目标：各模块基础功能跑通。**
- **王安安**：搭建机械臂硬件连接，安装机械臂 SDK，编写简单的 MATLAB 脚本验证能控制机械臂运动和读取力数据。
- **王梦瑶**：配置 OpenHaptics 开发环境，运行官方 Demo，确认 Touch 设备正常工作。
- **陈佳琪**：编写简单的 TCP 客户端/服务器测试程序，验证 PC-A 与 PC-B 之间的网络连通性。

### 第二阶段：核心模块开发
**目标：Touch 能发坐标，中继站能转换并控制机械臂。**
- **王梦瑶**：实现 Touch 坐标读取，并封装 TCP 客户端，能按协议格式发送坐标数据。
- **王安安**：完成 MATLAB 中继站基础框架：TCP 服务器监听、坐标转换算法集成、机械臂控制指令生成与发送。
- **张苏楠**：提供初版坐标转换矩阵和简单的滑动平均滤波器，供中继站调用。

### 第三阶段：闭环联调与算法集成
**目标：打通双向数据链路，实现力反馈闭环。**
- **王安安**：在中继站中集成力数据读取与回传功能。
- **王梦瑶**：在 Touch 程序中增加力数据接收与力反馈渲染。
- **陈佳琪**：协助排查通信中的粘包、断连、时延等问题。
- **张苏楠**：将滤波算法、安全边界检查集成到中继站中，并优化力映射参数。

### 第四阶段：系统优化与测试
**目标：全系统稳定运行，体验流畅。**
- **全员**：进行端到端测试，记录操作延迟、力反馈真实度。
- **王安安**：优化中继站日志显示与时延监控图表，确保长时间运行不卡顿。
- **王梦瑶**：调整力反馈增益，消除手柄抖动或震荡。
- **陈佳琪**：完善协议文档，总结通信调优经验。
