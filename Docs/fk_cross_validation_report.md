## Root Cause Analysis

C++ `mat4_translate()` adds translation in WORLD frame:
```cpp
T[0][3] += x;  T[1][3] += y;  T[2][3] += z;  // WRONG
```
MATLAB `T * tr(x,y,z)` multiplies in LOCAL frame (correct).

**Expected pattern if confirmed:**
- J1-only rotations → error ≈ 0 (first translate happens when T=I)
- J2-J6 non-zero → error grows as more rotations accumulate in T
- Error magnitude proportional to rotation angles between translations
